# Installation

## Prerequisites

- Go 1.21 or higher
- A running Neo4j instance (4.x or 5.x)

## Install neogo

<Steps>

1. **Add neogo to your project**

   ```bash
   go get github.com/rlch/neogo
   ```

2. **Import neogo in your code**

   ```go
   import "github.com/rlch/neogo"
   ```

3. **Create a neogo driver**

   ```go
   import (
       "github.com/neo4j/neo4j-go-driver/v5/neo4j"
       "github.com/rlch/neogo"
   )

   driver, err := neogo.New(
       "neo4j://localhost:7687",
       neo4j.BasicAuth("neo4j", "password", ""),
   )
   if err != nil {
       log.Fatal(err)
   }
   defer driver.DB().Close(ctx)
   ```

</Steps>

## Verify Installation

Run a simple query to verify everything is working:

```go
package main

import (
    "context"
    "fmt"
    "log"

    "github.com/neo4j/neo4j-go-driver/v5/neo4j"
    "github.com/rlch/neogo"
)

type Person struct {
    neogo.Node `neo4j:"Person"`
    Name string `neo4j:"name"`
}

func main() {
    ctx := context.Background()

    driver, err := neogo.New(
        "neo4j://localhost:7687",
        neo4j.BasicAuth("neo4j", "password", ""),
        neogo.WithTypes(&Person{}),
    )
    if err != nil {
        log.Fatal(err)
    }
    defer driver.DB().Close(ctx)

    // Create a test node
    err = driver.Exec().
        Cypher(`CREATE (p:Person {id: $id, name: $name})`).
        RunWithParams(ctx, map[string]any{
            "id":   "test-123",
            "name": "Test User",
        })
    if err != nil {
        log.Fatal(err)
    }

    // Query it back
    var person Person
    err = driver.Exec().
        Cypher(`MATCH (p:Person {id: $id}) RETURN p`).
        RunWithParams(ctx, map[string]any{"id": "test-123"}, "p", &person)
    if err != nil {
        log.Fatal(err)
    }

    fmt.Printf("Successfully queried: %+v\n", person)

    // Clean up
    err = driver.Exec().
        Cypher(`MATCH (p:Person {id: $id}) DELETE p`).
        RunWithParams(ctx, map[string]any{"id": "test-123"})
    if err != nil {
        log.Fatal(err)
    }
}
```

## Configuration Options

### Register Types

Register your node and relationship types for schema management:

```go
driver, err := neogo.New(
    "neo4j://localhost:7687",
    neo4j.BasicAuth("neo4j", "password", ""),
    neogo.WithTypes(&Person{}, &Movie{}, &ActedIn{}),
)
```

### Causal Consistency

Enable causal consistency for distributed reads:

```go
driver, err := neogo.New(
    "neo4j://localhost:7687",
    neo4j.BasicAuth("neo4j", "password", ""),
    neogo.WithCausalConsistency(func(ctx context.Context) string {
        // Return a key that identifies the causal chain (e.g., user ID)
        return getUserID(ctx)
    }),
)
```
