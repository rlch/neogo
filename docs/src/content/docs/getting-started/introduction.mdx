# Introduction to neogo

**neogo** is a lightweight Golang ORM for Neo4j that lets you write raw Cypher queries with type-safe result binding. Instead of a complex query builder, neogo provides a thin layer over the official Neo4j Go driver focused on marshalling/unmarshalling between Go structs and Neo4j.

<Aside type="caution" title="Experimental API">
  The neogo API is still in an experimental phase. Expect minor changes and additions until the first release.
</Aside>

## Why neogo?

Working with Neo4j in Go traditionally involves:
- Writing raw Cypher queries as strings ✓
- Manually extracting results from records
- Writing boilerplate code to marshal/unmarshal data
- Managing parameter binding carefully

neogo keeps the parts that work (raw Cypher) and automates the tedious parts:

- **Automatic marshalling/unmarshalling** - Results bind directly to Go structs
- **Named result binding** - Simple `"name", &pointer` pairs map Cypher RETURN items
- **Schema from struct tags** - Define indexes/constraints once on your types
- **Session/transaction helpers** - Convenient wrappers with causal consistency support
- **Zero-reflection hot path** - Pre-compiled codecs for high performance

## Key Concepts

### Nodes

Neo4j nodes are represented as Go structs embedding `neogo.Node`:

```go
import "github.com/rlch/neogo"

type Person struct {
    neogo.Node `neo4j:"Person"`

    Name    string `neo4j:"name"`
    Surname string `neo4j:"surname"`
    Age     int    `neo4j:"age"`
}
```

### Relationships

Relationships embed `neogo.Relationship`:

```go
type FriendsWith struct {
    neogo.Relationship `neo4j:"FRIENDS_WITH"`

    Since time.Time `neo4j:"since"`
}
```

### Query Execution

Write raw Cypher and bind results:

```go
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person {name: $name}) RETURN p`).
    RunWithParams(ctx, map[string]any{"name": "Alice"}, "p", &person)
```

The bindings are `"name", &pointer` pairs that map Cypher RETURN columns to Go variables.
