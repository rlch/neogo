# Quick Start

This guide walks you through writing your first neogo queries. You'll learn how to define models, connect to Neo4j, and execute Cypher queries with result binding.

## Define Your Models

<Steps>

1. **Define a Node**

   Create a Go struct that embeds `neogo.Node` and use struct tags to map fields to Neo4j properties:

   ```go
   import "github.com/rlch/neogo"

   type Person struct {
       neogo.Node `neo4j:"Person"`

       Name string `neo4j:"name"`
       Age  int    `neo4j:"age"`
   }
   ```

2. **Define a Relationship**

   Similarly, create relationship types by embedding `neogo.Relationship`:

   ```go
   type Knows struct {
       neogo.Relationship `neo4j:"KNOWS"`

       Since int `neo4j:"since"`
   }
   ```

3. **Create the Driver**

   ```go
   import (
       "github.com/neo4j/neo4j-go-driver/v5/neo4j"
       "github.com/rlch/neogo"
   )

   driver, err := neogo.New(
       "neo4j://localhost:7687",
       neo4j.BasicAuth("neo4j", "password", ""),
       neogo.WithTypes(&Person{}, &Knows{}),
   )
   if err != nil {
       log.Fatal(err)
   }
   defer driver.DB().Close(ctx)
   ```

</Steps>

## Writing Queries

### Create Data

```go
// Create a person with parameters
err := driver.Exec().
    Cypher(`
        CREATE (p:Person {id: $id, name: $name, age: $age})
    `).
    RunWithParams(ctx, map[string]any{
        "id":   "person-1",
        "name": "Alice",
        "age":  30,
    })
```

### Query with Result Binding

```go
// Query a single person
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person {name: $name}) RETURN p`).
    RunWithParams(ctx, map[string]any{"name": "Alice"}, "p", &person)

fmt.Printf("Found: %s, age %d\n", person.Name, person.Age)
```

### Query Multiple Results

```go
// Query returns a slice when binding to a slice type
var people []Person
err := driver.Exec().
    Cypher(`
        MATCH (p:Person)
        WHERE p.age > $minAge
        RETURN p
    `).
    RunWithParams(ctx, map[string]any{"minAge": 18}, "p", &people)

for _, p := range people {
    fmt.Printf("Adult: %s\n", p.Name)
}
```

### Multiple Bindings

```go
// Bind multiple RETURN values
var person Person
var friendCount int64

err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})-[:KNOWS]->(f:Person)
        WITH p, count(f) AS cnt
        RETURN p, cnt
    `).
    RunWithParams(ctx, map[string]any{"id": "person-1"}, 
        "p", &person, 
        "cnt", &friendCount)

fmt.Printf("%s has %d friends\n", person.Name, friendCount)
```

### Batch Operations with UNWIND

```go
people := []map[string]any{
    {"name": "Alice", "age": 30},
    {"name": "Bob", "age": 25},
    {"name": "Charlie", "age": 35},
}

err := driver.Exec().
    Cypher(`
        UNWIND $people AS data
        CREATE (p:Person)
        SET p = data
    `).
    RunWithParams(ctx, map[string]any{"people": people})
```

## Update and Delete

### Update

```go
err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})
        SET p.age = $newAge
    `).
    RunWithParams(ctx, map[string]any{
        "id":     "person-1",
        "newAge": 31,
    })
```

### Delete

```go
err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})
        DETACH DELETE p
    `).
    RunWithParams(ctx, map[string]any{"id": "person-1"})
```

### Delete with Return

```go
var count int64
err := driver.Exec().
    Cypher(`
        MATCH (p:Person {status: $status})
        WITH count(p) AS cnt, collect(p) AS nodes
        UNWIND nodes AS p
        DETACH DELETE p
        RETURN cnt
    `).
    RunWithParams(ctx, map[string]any{"status": "inactive"}, "cnt", &count)

fmt.Printf("Deleted %d inactive users\n", count)
```

## Relationships

### Create Relationships

```go
err := driver.Exec().
    Cypher(`
        MATCH (a:Person {name: $name1})
        MATCH (b:Person {name: $name2})
        CREATE (a)-[:KNOWS {since: $since}]->(b)
    `).
    RunWithParams(ctx, map[string]any{
        "name1": "Alice",
        "name2": "Bob",
        "since": 2023,
    })
```

### Query with Relationships

```go
var friends []Person

err := driver.Exec().
    Cypher(`
        MATCH (p:Person {name: $name})-[:KNOWS]->(friend:Person)
        RETURN friend
    `).
    RunWithParams(ctx, map[string]any{"name": "Alice"}, "friend", &friends)
```

## Debugging

Use `.Print()` to see the Cypher query and parameters:

```go
err := driver.Exec().
    Cypher(`MATCH (p:Person) WHERE p.age > $minAge RETURN p`).
    Print().  // Prints the Cypher to stdout
    RunWithParams(ctx, map[string]any{"minAge": 18}, "p", &people)
```

<Aside type="tip">
  `.Print()` is invaluable for debugging. It shows the exact Cypher that will be executed.
</Aside>
