# API Reference

This page provides a comprehensive reference for neogo's public API.

<Aside>
  For detailed Go documentation, see the [pkg.go.dev reference](https://pkg.go.dev/github.com/rlch/neogo).
</Aside>

## Driver

### neogo.New

Creates a new neogo Driver from connection parameters.

```go
func New(
    target string,
    auth auth.TokenManager,
    configurers ...Configurer,
) (Driver, error)
```

Example:
```go
driver, err := neogo.New(
    "neo4j://localhost:7687",
    neo4j.BasicAuth("neo4j", "password", ""),
    neogo.WithTypes(&Person{}, &Movie{}),
)
```

### Driver Interface

```go
type Driver interface {
    // Registry returns the internal registry used by this driver.
    Registry() *neogo.Registry

    // DB returns the underlying neo4j driver.
    DB() neo4j.DriverWithContext

    // Schema returns the schema interface for introspection and migration.
    Schema() Schema

    // ReadSession creates a new read-access session.
    ReadSession(ctx context.Context, configurers ...func(*neo4j.SessionConfig)) ReadSession

    // WriteSession creates a new write-access session.
    WriteSession(ctx context.Context, configurers ...func(*neo4j.SessionConfig)) WriteSession

    // Exec creates a new session and returns a Client for executing queries.
    Exec(configurers ...func(*execConfig)) Client
}
```

## Client Interface

The query interface returned by `Driver.Exec()`.

```go
type Client interface {
    // Cypher sets the Cypher query string and returns a Runner for execution.
    Cypher(query string) Runner
}
```

## Runner Interface

Executes Cypher queries with bindings.

```go
type Runner interface {
    // Print prints the query to stdout for debugging.
    Print() Runner

    // Run executes the query with bindings.
    // Bindings should be pairs of (name string, target any).
    Run(ctx context.Context, bindings ...any) error

    // RunWithParams executes the query with parameters and bindings.
    RunWithParams(ctx context.Context, params map[string]any, bindings ...any) error

    // Stream executes the query and streams results one-by-one.
    // Bindings should be pairs of (name string, target any).
    Stream(ctx context.Context, sink func() error, bindings ...any) error

    // StreamWithParams executes the query with parameters and streams results.
    StreamWithParams(ctx context.Context, params map[string]any, sink func() error, bindings ...any) error
}
```

### Usage Examples

```go
// Run without params, no return
err := driver.Exec().Cypher(`CREATE (n:Node)`).Run(ctx)

// Run without params, with bindings
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p LIMIT 1`).
    Run(ctx, "p", &person)

// RunWithParams
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) RETURN p`).
    RunWithParams(ctx, map[string]any{"id": "123"}, "p", &person)

// Stream
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Stream(ctx, func() error {
        fmt.Println(person.Name)
        return nil
    }, "p", &person)

// StreamWithParams
err := driver.Exec().
    Cypher(`MATCH (p:Person) WHERE p.age > $minAge RETURN p`).
    StreamWithParams(ctx, map[string]any{"minAge": 18}, func() error {
        fmt.Println(person.Name)
        return nil
    }, "p", &person)
```

## Sessions

### ReadSession Interface

```go
type ReadSession interface {
    // Session returns the underlying Neo4J session.
    Session() neo4j.SessionWithContext
    
    // Close closes the session.
    Close(ctx context.Context, joinedErrors ...error) error
    
    // ReadTransaction executes work in a read transaction with retry logic.
    ReadTransaction(ctx context.Context, work Work, configurers ...func(*neo4j.TransactionConfig)) error
    
    // BeginTransaction starts an explicit transaction.
    BeginTransaction(ctx context.Context, configurers ...func(*neo4j.TransactionConfig)) (Transaction, error)
}
```

### WriteSession Interface

```go
type WriteSession interface {
    ReadSession
    
    // WriteTransaction executes work in a write transaction with retry logic.
    WriteTransaction(ctx context.Context, work Work, configurers ...func(*neo4j.TransactionConfig)) error
}
```

### Work Function

```go
type Work func(c Client) error
```

## Transaction Interface

```go
type Transaction interface {
    // Run executes work within the transaction.
    Run(work Work) error
    
    // Commit commits the transaction.
    Commit(ctx context.Context) error
    
    // Rollback rolls back the transaction.
    Rollback(ctx context.Context) error
    
    // Close rolls back if not committed and closes resources.
    Close(ctx context.Context, joinedErrors ...error) error
}
```

## Configuration

### Configurer Functions

```go
// WithTypes registers types (INode, IRelationship, IAbstract) with the driver.

// WithCausalConsistency enables causal consistency using the provided key function.
func WithCausalConsistency(when func(ctx context.Context) string) Configurer

func WithTxConfig(configurers ...func(*neo4j.TransactionConfig)) func(ec *execConfig)
```

## Schema Interface

```go
type Schema interface {
    // GetIndexes returns all indexes in the database.
    GetIndexes(ctx context.Context) ([]IndexInfo, error)
    
    // GetConstraints returns all constraints in the database.
    GetConstraints(ctx context.Context) ([]ConstraintInfo, error)
    
    // AutoMigrate creates indexes and constraints from registered types.
    AutoMigrate(ctx context.Context) ([]MigrationAction, error)
    
    // NeedsMigration checks if any indexes/constraints are missing.
    NeedsMigration(ctx context.Context) (bool, error)
}
```

## Struct Tags

### neo4j Tag

Used on embedded `neogo.Node` or `neogo.Relationship` to specify labels/types:

```go
type Person struct {
    neogo.Node `neo4j:"Person"`        // Single label
}

type Actor struct {
    neogo.Node `neo4j:"Person,Actor"`  // Multiple labels
}

type FriendsWith struct {
    neogo.Relationship `neo4j:"FRIENDS_WITH"`
}
```

Used on fields to specify property names:

```go
type Person struct {
    neogo.Node `neo4j:"Person"`

    Name      string    `neo4j:"name"`
    BirthDate time.Time `neo4j:"birth_date"`
}
```

### Schema Tags

```go
type Person struct {
    neogo.Node `neo4j:"Person"`

    Email string `neo4j:"email,unique"`           // Unique constraint
    Name  string `neo4j:"name,index"`             // Range index
    Bio   string `neo4j:"bio,fulltext"`           // Fulltext index
    Age   int    `neo4j:"age,notNull"`            // Not null constraint
}
```
