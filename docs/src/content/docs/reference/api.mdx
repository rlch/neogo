# API Reference

This page provides a comprehensive reference for neogo's public API.

<Aside>
  For detailed Go documentation, see the [pkg.go.dev reference](https://pkg.go.dev/github.com/rlch/neogo).
</Aside>

## Core Types

### neogo.Node

Embedded in structs to define Neo4j nodes.

```go
type Node struct {
    ID string
}

// Methods
func (n *Node) GenerateID()  // Generates a UUID for the node
```

### neogo.Relationship

Embedded in structs to define Neo4j relationships.

```go
type Relationship struct {
    // Internal fields
}
```

### neogo.INode

Interface that all node types implement.

```go
type INode interface {
    GetID() string
    SetID(string)
}
```

## Client

### neogo.New

Creates a new neogo client from a Neo4j driver.

```go
func New(driver neo4j.DriverWithContext) *Client
```

### Client.Exec

Starts a new query builder.

```go
func (c *Client) Exec() *QueryBuilder
```

### Client.WithTx

Returns a client that uses a specific transaction.

```go
func (c *Client) WithTx(tx neo4j.ManagedTransaction) *Client
```

## Struct Tags

### neo4j Tag

Used on embedded `neogo.Node` or `neogo.Relationship` to specify labels/types:

```go
type Person struct {
    neogo.Node `neo4j:"Person"`        // Single label
}

type Actor struct {
    neogo.Node `neo4j:"Person,Actor"`  // Multiple labels
}

type FriendsWith struct {
    neogo.Relationship `neo4j:"FRIENDS_WITH"`
}
```

Used on fields to specify property names:

```go
type Person struct {
    neogo.Node `neo4j:"Person"`

    Name      string    `neo4j:"name"`
    BirthDate time.Time `neo4j:"birth_date"`
}
```
