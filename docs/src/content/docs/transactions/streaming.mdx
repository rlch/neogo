Streaming allows you to process query results one at a time without loading the entire result set into memory. This is essential for handling large datasets efficiently.

## Basic Streaming

### Stream Method

```go
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person) WHERE p.active = true RETURN p`).
    Stream(ctx, func() error {
        // Called for each record
        fmt.Printf("Processing: %s\n", person.Name)
        return nil
    }, "p", &person)
```

### Stream with Parameters

```go
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person) WHERE p.age > $minAge RETURN p`).
    StreamWithParams(ctx, map[string]any{"minAge": 18}, func() error {
        fmt.Printf("Adult: %s, age %d\n", person.Name, person.Age)
        return nil
    }, "p", &person)
```

## Stream vs Run

<Tabs>
<TabItem label="Stream (Memory Efficient)">
```go
// Processes one result at a time
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Stream(ctx, func() error {
        process(person)
        return nil
    }, "p", &person)
```
Memory usage: O(1) - constant
</TabItem>
<TabItem label="Run (Loads Everything)">
```go
// Loads all results into memory first
var people []Person
err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Run(ctx, "p", &people)

for _, p := range people {
    process(p)
}
```
Memory usage: O(n) - linear with result size
</TabItem>
</Tabs>

## Error Handling

### Stop on Error

Return an error to stop streaming:

```go
var processedCount int

err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Stream(ctx, func() error {
        if err := validatePerson(person); err != nil {
            return fmt.Errorf("failed at record %d: %w", processedCount, err)
        }
        processedCount++
        return nil
    }, "p", &person)

if err != nil {
    fmt.Printf("Processed %d records before error\n", processedCount)
}
```

### Early Termination

Use a sentinel error to stop early without error:

```go
var ErrStopIteration = errors.New("stop iteration")
var found *Person

err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Stream(ctx, func() error {
        if person.Email == targetEmail {
            found = &Person{Name: person.Name, Email: person.Email}
            return ErrStopIteration
        }
        return nil
    }, "p", &person)

if err != nil && !errors.Is(err, ErrStopIteration) {
    return err
}

if found != nil {
    fmt.Printf("Found: %s\n", found.Name)
}
```

## Streaming in Transactions

### With ReadTransaction

```go
session := driver.ReadSession(ctx)
defer session.Close(ctx)

err := session.ReadTransaction(ctx, func(c neogo.Client) error {
    var person Person
    return c.Cypher(`MATCH (p:Person) WHERE p.active = true RETURN p`).
        Stream(ctx, func() error {
            return processInTransaction(person)
        }, "p", &person)
})
```

## Aggregation During Streaming

### Count

```go
var count int
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Stream(ctx, func() error {
        count++
        return nil
    }, "p", &person)

fmt.Printf("Total: %d\n", count)
```

### Custom Aggregation

```go
var (
    totalAge int
    count    int
    maxAge   int
)
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Stream(ctx, func() error {
        totalAge += person.Age
        count++
        if person.Age > maxAge {
            maxAge = person.Age
        }
        return nil
    }, "p", &person)

avgAge := float64(totalAge) / float64(count)
fmt.Printf("Average age: %.2f, Max age: %d\n", avgAge, maxAge)
```

## Batch Processing

### Process in Batches

```go
const batchSize = 100
var batch []Person
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Stream(ctx, func() error {
        batch = append(batch, person)

        if len(batch) >= batchSize {
            if err := processBatch(batch); err != nil {
                return err
            }
            batch = batch[:0]  // Reset slice
        }
        return nil
    }, "p", &person)

if err != nil {
    return err
}

// Process remaining
if len(batch) > 0 {
    return processBatch(batch)
}
```

## Memory-Efficient Export

### Export to File

```go
file, err := os.Create("people.json")
if err != nil {
    return err
}
defer file.Close()

encoder := json.NewEncoder(file)
first := true
var person Person

file.WriteString("[")

err = driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Stream(ctx, func() error {
        if !first {
            file.WriteString(",")
        }
        first = false
        return encoder.Encode(person)
    }, "p", &person)

file.WriteString("]")
```

### Stream to HTTP Response

```go
func (h *Handler) ExportPeople(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/x-ndjson")

    session := h.driver.ReadSession(r.Context())
    defer session.Close(r.Context())

    encoder := json.NewEncoder(w)
    var person Person

    err := session.ReadTransaction(r.Context(), func(c neogo.Client) error {
        return c.Cypher(`MATCH (p:Person) RETURN p`).
            Stream(r.Context(), func() error {
                return encoder.Encode(person)
            }, "p", &person)
    })

    if err != nil {
        log.Printf("Stream error: %v", err)
    }
}
```

## Multiple Bindings in Stream

Stream can bind multiple values per record:

```go
var person Person
var friendCount int64

err := driver.Exec().
    Cypher(`
        MATCH (p:Person)-[:KNOWS]->(f:Person)
        WITH p, count(f) AS cnt
        RETURN p, cnt
    `).
    Stream(ctx, func() error {
        fmt.Printf("%s has %d friends\n", person.Name, friendCount)
        return nil
    }, "p", &person, "cnt", &friendCount)
```

## Performance Tips

<Aside type="tip" title="Streaming Guidelines">

1. **Use streaming for large results**: >1000 records
2. **Process inline**: Avoid storing all results in memory
3. **Handle errors properly**: Stop streaming on critical errors
4. **Use batching**: For downstream systems that prefer batches
5. **Monitor memory**: Even streaming can accumulate state in your callback

</Aside>

### When to Use Each Method

| Scenario | Method | Reason |
|----------|--------|--------|
| < 100 results | `Run()` | Simple, low overhead |
| 100-1000 results | Either | Depends on memory constraints |
| > 1000 results | `Stream()` | Memory efficiency |
| Export to file | `Stream()` | Constant memory |
| Need random access | `Run()` | Must load all data |
