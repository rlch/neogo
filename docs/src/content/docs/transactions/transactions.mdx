Transactions group multiple operations into atomic units. Either all operations succeed, or all are rolled back.

## Transaction Types

Neo4j supports three transaction types:

| Type | Use Case | Retry | Rollback |
|------|----------|-------|----------|
| Auto-commit | Simple queries via `Exec()` | No | No |
| Managed | Most operations | Yes | Automatic |
| Explicit | Fine control | Manual | Manual |

## Managed Transactions (Recommended)

### ReadTransaction

For read-only transactions with automatic retry:

```go
session := driver.ReadSession(ctx)
defer session.Close(ctx)

err := session.ReadTransaction(ctx, func(c neogo.Client) error {
    var people []Person
    return c.Cypher(`MATCH (p:Person) WHERE p.active = true RETURN p`).
        Run(ctx, "p", &people)
})
```

### WriteTransaction

For write transactions with automatic retry:

```go
session := driver.WriteSession(ctx)
defer session.Close(ctx)

err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    return c.Cypher(`
        CREATE (p:Person {id: $id, name: $name, email: $email})
    `).RunWithParams(ctx, map[string]any{
        "id":    "person-123",
        "name":  "Alice",
        "email": "alice@example.com",
    })
})
```

<Aside type="tip">
Use `ReadTransaction` and `WriteTransaction` for most operations. They handle retries for transient failures automatically.
</Aside>

## Multiple Operations in a Transaction

### Atomic Operations

```go
session := driver.WriteSession(ctx)
defer session.Close(ctx)

err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    // Create Alice
    if err := c.Cypher(`CREATE (p:Person {id: 'alice', name: 'Alice'})`).
        Run(ctx); err != nil {
        return err  // Transaction will rollback
    }

    // Create Bob
    if err := c.Cypher(`CREATE (p:Person {id: 'bob', name: 'Bob'})`).
        Run(ctx); err != nil {
        return err  // Transaction will rollback
    }

    // Create relationship
    if err := c.Cypher(`
        MATCH (a:Person {id: 'alice'})
        MATCH (b:Person {id: 'bob'})
        CREATE (a)-[:KNOWS]->(b)
    `).Run(ctx); err != nil {
        return err  // Transaction will rollback
    }

    return nil
})
```

## Explicit Transactions

For fine-grained control:

```go
session := driver.WriteSession(ctx)
defer session.Close(ctx)

tx, err := session.BeginTransaction(ctx)
if err != nil {
    return err
}

// Operation 1
err = tx.Run(func(c neogo.Client) error {
    return c.Cypher(`CREATE (p:Person {name: $name})`).
        RunWithParams(ctx, map[string]any{"name": "Alice"})
})
if err != nil {
    tx.Rollback(ctx)
    return err
}

// Operation 2
err = tx.Run(func(c neogo.Client) error {
    return c.Cypher(`
        MATCH (p:Person {name: 'Alice'})
        SET p.verified = true
    `).Run(ctx)
})
if err != nil {
    tx.Rollback(ctx)
    return err
}

// Commit
if err := tx.Commit(ctx); err != nil {
    return err
}

tx.Close(ctx)
```

### Simplified Error Handling

Use `Close` with joined errors:

```go
tx, err := session.BeginTransaction(ctx)
if err != nil {
    return err
}

workErr := tx.Run(func(c neogo.Client) error {
    // Do work...
    return nil
})

// Close will rollback if not committed, and join any errors
return tx.Close(ctx, workErr)
```

## Transaction Configuration

### Timeout

```go
err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    return c.Cypher(`...`).Run(ctx)
}, func(tc *neo4j.TransactionConfig) {
    tc.Timeout = 30 * time.Second
})
```

### Metadata

```go
err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    return c.Cypher(`...`).Run(ctx)
}, func(tc *neo4j.TransactionConfig) {
    tc.Metadata = map[string]any{
        "app":  "myapp",
        "user": userID,
    }
})
```

## Error Handling

### Retryable Errors

Managed transactions automatically retry on:
- Transient errors (deadlocks, leader changes)
- Service unavailability

```go
err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    // This will be retried on transient failures
    return c.Cypher(`...`).Run(ctx)
})
```

### Non-Retryable Errors

Return errors to stop retries:

```go
err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    // Validate input first
    if !isValid(input) {
        // This error won't be retried
        return fmt.Errorf("invalid input: %v", input)
    }

    return c.Cypher(`...`).RunWithParams(ctx, map[string]any{...})
})
```

## Transaction Patterns

### Read-Modify-Write

```go
err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    // Read current balance
    var balance int64
    if err := c.Cypher(`
        MATCH (a:Account {id: $id})
        RETURN a.balance
    `).RunWithParams(ctx, map[string]any{"id": accountID}, "a.balance", &balance); err != nil {
        return err
    }

    // Check balance
    if balance < amount {
        return fmt.Errorf("insufficient funds")
    }

    // Update balance
    return c.Cypher(`
        MATCH (a:Account {id: $id})
        SET a.balance = $newBalance
    `).RunWithParams(ctx, map[string]any{
        "id":         accountID,
        "newBalance": balance - amount,
    })
})
```

### Upsert Pattern

```go
err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    return c.Cypher(`
        MERGE (u:User {email: $email})
        ON CREATE SET u.id = $id, u.createdAt = datetime()
        ON MATCH SET u.lastLogin = datetime()
    `).RunWithParams(ctx, map[string]any{
        "id":    newID,
        "email": email,
    })
})
```

## Best Practices

<Aside type="tip" title="Transaction Guidelines">

1. **Keep transactions short**: Long transactions hold locks
2. **Use managed transactions**: Auto-retry handles transient failures
3. **Don't mix access modes**: Read in read transactions, write in write transactions
4. **Handle all errors**: Return errors to trigger rollback
5. **Avoid external calls**: Don't call APIs/services inside transactions
6. **Idempotent operations**: Design for possible retries

</Aside>

### Anti-Patterns

```go
// ❌ Bad: External call in transaction
err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    // Don't do this - HTTP call inside transaction
    resp, err := http.Get("https://api.example.com/data")
    if err != nil {
        return err
    }
    // ...
})

// ✅ Good: External call before transaction
resp, err := http.Get("https://api.example.com/data")
if err != nil {
    return err
}

err = session.WriteTransaction(ctx, func(c neogo.Client) error {
    // Use data from external call
    return c.Cypher(`...`).RunWithParams(ctx, map[string]any{
        "data": resp.Data,
    })
})
```
