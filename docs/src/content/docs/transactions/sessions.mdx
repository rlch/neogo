Sessions are the primary way to interact with Neo4j. They manage connections, transactions, and query execution.

## Creating Sessions

### Read Session

For read-only operations:

```go
session := driver.ReadSession(ctx)
defer session.Close(ctx)

err := session.ReadTransaction(ctx, func(c neogo.Client) error {
    var people []Person
    return c.Cypher(`MATCH (p:Person) RETURN p`).
        Run(ctx, "p", &people)
})
```

### Write Session

For write operations:

```go
session := driver.WriteSession(ctx)
defer session.Close(ctx)

err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    return c.Cypher(`CREATE (p:Person {name: $name})`).
        RunWithParams(ctx, map[string]any{"name": "Alice"})
})
```

<Aside type="tip">
Use read sessions when possible. Neo4j can route read queries to replicas in a cluster, improving performance.
</Aside>

### Session Configuration

```go
session := driver.ReadSession(ctx, func(sc *neo4j.SessionConfig) {
    sc.DatabaseName = "mydb"
    sc.FetchSize = 1000
})
```

## Managed Transactions

Managed transactions handle retries for transient failures automatically.

### ReadTransaction

```go
session := driver.ReadSession(ctx)
defer session.Close(ctx)

err := session.ReadTransaction(ctx, func(c neogo.Client) error {
    var person Person
    return c.Cypher(`MATCH (p:Person {name: $name}) RETURN p`).
        RunWithParams(ctx, map[string]any{"name": "Alice"}, "p", &person)
})
```

### WriteTransaction

```go
session := driver.WriteSession(ctx)
defer session.Close(ctx)

err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    return c.Cypher(`
        MATCH (a:Person {name: $name1})
        MATCH (b:Person {name: $name2})
        CREATE (a)-[:KNOWS]->(b)
    `).RunWithParams(ctx, map[string]any{
        "name1": "Alice",
        "name2": "Bob",
    })
})
```

### Multiple Operations in a Transaction

```go
err := session.WriteTransaction(ctx, func(c neogo.Client) error {
    // Operation 1: Create Alice
    if err := c.Cypher(`CREATE (p:Person {id: $id, name: 'Alice'})`).
        RunWithParams(ctx, map[string]any{"id": "alice-1"}); err != nil {
        return err  // Transaction will rollback
    }

    // Operation 2: Create Bob
    if err := c.Cypher(`CREATE (p:Person {id: $id, name: 'Bob'})`).
        RunWithParams(ctx, map[string]any{"id": "bob-1"}); err != nil {
        return err  // Transaction will rollback
    }

    // Operation 3: Connect them
    return c.Cypher(`
        MATCH (a:Person {id: 'alice-1'})
        MATCH (b:Person {id: 'bob-1'})
        CREATE (a)-[:KNOWS]->(b)
    `).Run(ctx)
})
```

## Explicit Transactions

For fine-grained control:

```go
session := driver.WriteSession(ctx)
defer session.Close(ctx)

tx, err := session.BeginTransaction(ctx)
if err != nil {
    return err
}

// Run operations
err = tx.Run(func(c neogo.Client) error {
    return c.Cypher(`CREATE (p:Person {name: $name})`).
        RunWithParams(ctx, map[string]any{"name": "Alice"})
})
if err != nil {
    tx.Rollback(ctx)
    return err
}

err = tx.Run(func(c neogo.Client) error {
    return c.Cypher(`CREATE (p:Person {name: $name})`).
        RunWithParams(ctx, map[string]any{"name": "Bob"})
})
if err != nil {
    tx.Rollback(ctx)
    return err
}

// Commit
err = tx.Commit(ctx)
if err != nil {
    return err
}

// Always close
tx.Close(ctx)
```

### Simplified Close with Errors

The `Close` method can join errors:

```go
tx, err := session.BeginTransaction(ctx)
if err != nil {
    return err
}

workErr := tx.Run(func(c neogo.Client) error {
    return c.Cypher(`...`).Run(ctx)
})

// Close will rollback if not committed, and join any errors
return tx.Close(ctx, workErr)
```

## Auto-Commit (Exec)

For simple queries that don't need explicit session management:

```go
// Driver.Exec() creates and manages its own session
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) RETURN p`).
    RunWithParams(ctx, map[string]any{"id": "123"}, "p", &person)
```

<Aside type="note">
`Exec()` creates a new session for each query and infers read/write mode from the Cypher. Use explicit sessions for transactions or multiple related queries.
</Aside>

### Exec Configuration

```go
// Configure session for Exec
err := driver.Exec(
    neogo.WithSessionConfig(func(sc *neo4j.SessionConfig) {
        sc.DatabaseName = "mydb"
    }),
    neogo.WithTxConfig(func(tc *neo4j.TransactionConfig) {
        tc.Timeout = 30 * time.Second
    }),
).Cypher(`MATCH (p:Person) RETURN p`).
    Run(ctx, "p", &people)
```

## Session Lifecycle

### Proper Cleanup

Always close sessions:

```go
session := driver.ReadSession(ctx)
defer session.Close(ctx)  // Important!

// Use session...
```

### Close with Errors

Session.Close can join errors:

```go
session := driver.WriteSession(ctx)
defer func() {
    if err := session.Close(ctx, workErr); err != nil {
        log.Printf("Session close error: %v", err)
    }
}()
```

## Causal Consistency

neogo supports causal consistency via bookmarks.

### Enable at Driver Level

```go
driver, err := neogo.New(
    "neo4j://localhost:7687",
    neo4j.BasicAuth("neo4j", "password", ""),
    neogo.WithCausalConsistency(func(ctx context.Context) string {
        // Return a key that identifies the causal chain
        return getUserID(ctx)
    }),
)
```

When enabled, writes store bookmarks and subsequent reads on the same key will use those bookmarks.

## Best Practices

<Aside type="tip" title="Session Guidelines">

1. **Short-lived sessions**: Create sessions per operation or request
2. **Always close**: Use `defer session.Close(ctx)`
3. **Use appropriate access mode**: Read sessions for queries, write sessions for mutations
4. **Use managed transactions**: Auto-retry handles transient failures
5. **Keep transactions short**: Long transactions hold locks

</Aside>

### HTTP Request Pattern

```go
func (h *Handler) GetPerson(w http.ResponseWriter, r *http.Request) {
    ctx := r.Context()
    id := r.URL.Query().Get("id")

    session := h.driver.ReadSession(ctx)
    defer session.Close(ctx)

    var person Person
    err := session.ReadTransaction(ctx, func(c neogo.Client) error {
        return c.Cypher(`MATCH (p:Person {id: $id}) RETURN p`).
            RunWithParams(ctx, map[string]any{"id": id}, "p", &person)
    })
    if err != nil {
        http.Error(w, err.Error(), http.StatusInternalServerError)
        return
    }

    json.NewEncoder(w).Encode(person)
}
```
