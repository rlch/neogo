neogo provides methods for creating nodes and relationships using Cypher's `CREATE` and `MERGE` clauses.

## Creating Nodes

### Basic CREATE

Create a single node:

```go
type Person struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

func (p *Person) Node() *db.NodePattern { return db.Node("Person") }

// Create a person
var person Person
cy := c.Create(
    db.Node(&person, db.Props{
        "name": "Alice",
        "age":  30,
    }),
)
```

Generated Cypher:
```cypher
CREATE (person:Person {name: "Alice", age: 30})
```

### CREATE with RETURN

Return the created node:

```go
var person Person

cy := c.Create(
    db.Node(&person, db.Props{
        "name": "Alice",
        "age":  30,
    }),
).Return(&person)

result, err := cy.Single(ctx, tx)
// result.Person contains the created node
```

### Creating Multiple Nodes

Create multiple nodes in one query:

```go
var alice, bob Person

cy := c.Create(
    db.Node(&alice, db.Props{"name": "Alice"}),
).Create(
    db.Node(&bob, db.Props{"name": "Bob"}),
).Return(&alice, &bob)
```

## Creating Relationships

### CREATE Relationship Between Existing Nodes

First MATCH the nodes, then CREATE the relationship:

```go
var alice, bob Person
var knows Knows

cy := c.Match(
    db.Node(&alice, db.Props{"name": "Alice"}),
).Match(
    db.Node(&bob, db.Props{"name": "Bob"}),
).Create(
    db.Patterns(
        db.Node(&alice),
        db.Related(&knows, db.To, &bob, db.Props{"since": 2023}),
    ),
).Return(&knows)
```

Generated Cypher:
```cypher
MATCH (alice:Person {name: "Alice"})
MATCH (bob:Person {name: "Bob"})
CREATE (alice)-[knows:KNOWS {since: 2023}]->(bob)
RETURN knows
```

### CREATE Node and Relationship Together

Create a complete pattern in one statement:

```go
var person, friend Person
var knows Knows

cy := c.Create(
    db.Patterns(
        db.Node(&person, db.Props{"name": "Alice"}),
        db.Related(&knows, db.To, &friend, db.Props{
            "name": "Bob",
        }),
    ),
).Return(&person, &knows, &friend)
```

Generated Cypher:
```cypher
CREATE (person:Person {name: "Alice"})-[knows:KNOWS]->(friend:Person {name: "Bob"})
RETURN person, knows, friend
```

## Using MERGE

MERGE creates nodes/relationships only if they don't exist.

### Basic MERGE

```go
var person Person

cy := c.Merge(
    db.Node(&person, db.Props{"name": "Alice"}),
).Return(&person)
```

Generated Cypher:
```cypher
MERGE (person:Person {name: "Alice"})
RETURN person
```

### MERGE with ON CREATE and ON MATCH

Set different properties depending on whether the node was created or matched:

```go
var person Person

cy := c.Merge(
    db.Node(&person, db.Props{"name": "Alice"}),
).OnCreate(
    db.SetPropValue(&person, "created_at", time.Now()),
).OnMatch(
    db.SetPropValue(&person, "last_seen", time.Now()),
).Return(&person)
```

Generated Cypher:
```cypher
MERGE (person:Person {name: "Alice"})
ON CREATE SET person.created_at = $p0
ON MATCH SET person.last_seen = $p1
RETURN person
```

### MERGE Relationships

```go
var alice, bob Person
var knows Knows

cy := c.Match(
    db.Node(&alice, db.Props{"name": "Alice"}),
).Match(
    db.Node(&bob, db.Props{"name": "Bob"}),
).Merge(
    db.Patterns(
        db.Node(&alice),
        db.Related(&knows, db.To, &bob),
    ),
).OnCreate(
    db.SetPropValue(&knows, "since", 2023),
).Return(&knows)
```

## Setting Properties

### Using db.Props

Inline properties in the pattern:

```go
cy := c.Create(
    db.Node(&person, db.Props{
        "name":    "Alice",
        "age":     30,
        "active":  true,
        "tags":    []string{"engineer", "golang"},
    }),
)
```

### Using SET After CREATE

```go
cy := c.Create(
    db.Node(&person),
).Set(
    db.SetPropValue(&person, "name", "Alice"),
    db.SetPropValue(&person, "age", 30),
).Return(&person)
```

### Using SetMerge for Multiple Properties

```go
cy := c.Create(
    db.Node(&person),
).Set(
    db.SetMerge(&person, db.Props{
        "name":   "Alice",
        "age":    30,
        "active": true,
    }),
).Return(&person)
```

Generated Cypher:
```cypher
CREATE (person:Person)
SET person += {name: "Alice", age: 30, active: true}
RETURN person
```

## Creating from Go Structs

Pass a struct with values to create from its data:

```go
person := Person{
    Name: "Alice",
    Age:  30,
}

cy := c.Create(
    db.Node(&person),  // Uses struct values as properties
).Return(&person)
```

<Aside type="note">
When creating from a struct, all non-zero fields are included as properties. Use `omitempty` in json tags to exclude zero values.
</Aside>

## Bulk Creation with UNWIND

Create multiple nodes efficiently:

```go
people := []map[string]any{
    {"name": "Alice", "age": 30},
    {"name": "Bob", "age": 25},
    {"name": "Charlie", "age": 35},
}

var person Person

cy := c.Unwind(people, "data").
    Create(
        db.Node(&person, db.Props{
            "name": db.Qual("data", "name"),
            "age":  db.Qual("data", "age"),
        }),
    ).Return(&person)
```

Generated Cypher:
```cypher
UNWIND $p0 AS data
CREATE (person:Person {name: data.name, age: data.age})
RETURN person
```

## Error Handling

### Constraint Violations

When a uniqueness constraint is violated:

```go
_, err := cy.Run(ctx, tx)
if neo4j.IsConstraintError(err) {
    // Handle duplicate
}
```

### Best Practices

<Aside type="tip" title="Creation Patterns">

1. **Use MERGE for idempotency**: When the same code might run multiple times
2. **Use CREATE for guaranteed new data**: When you know the data is unique
3. **Add constraints**: Use unique constraints to prevent duplicates
4. **Return created data**: Always RETURN to confirm what was created

</Aside>

## Complex Creation Example

Creating a graph structure:

```go
var company Company
var alice, bob Person  
var aliceWorks, bobWorks WorksAt
var aliceKnowsBob Knows

cy := c.Create(
    db.Node(&company, db.Props{"name": "Acme Corp"}),
).Create(
    db.Patterns(
        db.Node(&alice, db.Props{"name": "Alice"}),
        db.Related(&aliceWorks, db.To, &company, db.Props{"role": "Engineer"}),
    ),
).Create(
    db.Patterns(
        db.Node(&bob, db.Props{"name": "Bob"}),
        db.Related(&bobWorks, db.To, &company, db.Props{"role": "Manager"}),
    ),
).Create(
    db.Patterns(
        db.Node(&alice),
        db.Related(&aliceKnowsBob, db.To, &bob),
    ),
).Return(&company, &alice, &bob)
```
