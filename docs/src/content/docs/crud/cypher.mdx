# Cypher Queries

neogo uses raw Cypher queries for all database operations. You write the Cypher you know, pass parameters safely, and bind results to Go variables.

## Basic Pattern

<Steps>

1. **Write your Cypher query** using `Cypher()`
2. **Pass parameters** (if any) with a `map[string]any`
3. **Bind results** with `"name", &pointer` pairs

</Steps>

```go
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) RETURN p`).
    RunWithParams(ctx, map[string]any{"id": "user-123"}, "p", &person)
```

## Execution Methods

### Run (No Results)

For queries that don't return data:

```go
err := driver.Exec().
    Cypher(`CREATE (p:Person {name: $name, age: $age})`).
    RunWithParams(ctx, map[string]any{
        "name": "Alice",
        "age":  30,
    })
```

### Run with Bindings

For queries that return data, add `"name", &pointer` pairs after params:

```go
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) RETURN p`).
    RunWithParams(ctx, map[string]any{"id": "123"}, "p", &person)
```

### Run without Params

If you have no parameters, use `Run()`:

```go
var people []Person
err := driver.Exec().
    Cypher(`MATCH (p:Person) RETURN p`).
    Run(ctx, "p", &people)
```

## Result Binding

### Binding to Struct

```go
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) RETURN p`).
    RunWithParams(ctx, map[string]any{"id": "123"}, "p", &person)
```

### Binding to Slice

When multiple records are returned, bind to a slice:

```go
var people []Person

err := driver.Exec().
    Cypher(`MATCH (p:Person) WHERE p.age > $minAge RETURN p`).
    RunWithParams(ctx, map[string]any{"minAge": 18}, "p", &people)
```

### Binding Primitives

You can bind any type that matches the returned value:

```go
var name string
var age int64

err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) RETURN p.name, p.age`).
    RunWithParams(ctx, map[string]any{"id": "123"}, 
        "p.name", &name, 
        "p.age", &age)
```

### Multiple Bindings

Bind multiple RETURN values:

```go
var person Person
var friendCount int64
var friendNames []string

err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})-[:KNOWS]->(f:Person)
        WITH p, count(f) AS cnt, collect(f.name) AS names
        RETURN p, cnt, names
    `).
    RunWithParams(ctx, map[string]any{"id": "123"},
        "p", &person,
        "cnt", &friendCount,
        "names", &friendNames)
```

### Binding Maps/Structs

Bind computed maps to struct types:

```go
var result struct {
    UserID   string `json:"userID"`
    Name     string `json:"name"`
    FriendCount int `json:"friendCount"`
}

err := driver.Exec().
    Cypher(`
        MATCH (u:User {id: $id})-[:KNOWS]->(f)
        WITH {userID: u.id, name: u.name, friendCount: count(f)} AS data
        RETURN data
    `).
    RunWithParams(ctx, map[string]any{"id": "123"}, "data", &result)
```

## Parameter Injection

Always use parameters for dynamic values:

```go
// ✅ Good - prevents injection
err := driver.Exec().
    Cypher(`MATCH (u:User {id: $id}) RETURN u`).
    RunWithParams(ctx, map[string]any{"id": userID}, "u", &user)

// ❌ Bad - injection risk
err := driver.Exec().
    Cypher(fmt.Sprintf(`MATCH (u:User {id: '%s'}) RETURN u`, userID)).
    Run(ctx, "u", &user)
```

### Nested Parameters

```go
err := driver.Exec().
    Cypher(`
        MERGE (gu:User {id: $input.groupUserID})
        WITH gu
        UNWIND $input.userIDs AS userID
        MERGE (u:User {id: userID})
        MERGE (u)-[:IN_GROUP]->(gu)
    `).
    RunWithParams(ctx, map[string]any{
        "input": map[string]any{
            "groupUserID": "group-1",
            "userIDs":     []string{"user-1", "user-2"},
        },
    })
```

### UNWIND for Batch Operations

```go
inputs := []map[string]any{
    {"userID": "user-1", "name": "Alice"},
    {"userID": "user-2", "name": "Bob"},
}

err := driver.Exec().
    Cypher(`
        UNWIND $inputs AS input
        CREATE (u:User {id: input.userID, name: input.name})
    `).
    RunWithParams(ctx, map[string]any{"inputs": inputs})
```

## Streaming Results

For large result sets, use streaming to process one record at a time:

```go
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person) WHERE p.active = true RETURN p`).
    Stream(ctx, func() error {
        // Called for each record
        fmt.Printf("Processing: %s\n", person.Name)
        return nil
    }, "p", &person)
```

### Streaming with Parameters

```go
err := driver.Exec().
    Cypher(`MATCH (p:Person) WHERE p.age > $minAge RETURN p`).
    StreamWithParams(ctx, map[string]any{"minAge": 18}, func() error {
        processAdult(person)
        return nil
    }, "p", &person)
```

<Aside type="tip">
  Use `Stream` for large result sets to avoid loading everything into memory.
</Aside>

## Debugging

err := driver.Exec().

## Common Patterns

### CRUD Operations

```go
// Create
err := driver.Exec().
    Cypher(`CREATE (p:Person {id: $id, name: $name})`).
    RunWithParams(ctx, map[string]any{"id": id, "name": name})

// Read
var person Person
err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) RETURN p`).
    RunWithParams(ctx, map[string]any{"id": id}, "p", &person)

// Update
err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) SET p.name = $name`).
    RunWithParams(ctx, map[string]any{"id": id, "name": newName})

// Delete
err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id}) DETACH DELETE p`).
    RunWithParams(ctx, map[string]any{"id": id})
```

### Upsert with MERGE

```go
err := driver.Exec().
    Cypher(`
        MERGE (p:Person {id: $id})
        ON CREATE SET p.name = $name, p.createdAt = datetime()
        ON MATCH SET p.lastSeen = datetime()
    `).
    RunWithParams(ctx, map[string]any{"id": id, "name": name})
```

### Relationship Operations

```go
// Create relationship
err := driver.Exec().
    Cypher(`
        MATCH (a:Person {id: $aID})
        MATCH (b:Person {id: $bID})
        CREATE (a)-[:KNOWS {since: $since}]->(b)
    `).
    RunWithParams(ctx, map[string]any{
        "aID": "person-1",
        "bID": "person-2",
        "since": 2023,
    })

// Query with relationships
var friends []Person
err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})-[:KNOWS]->(friend:Person)
        RETURN friend
    `).
    RunWithParams(ctx, map[string]any{"id": "person-1"}, "friend", &friends)
```

### Aggregation

```go
var stats struct {
    Total   int64   `json:"total"`
    AvgAge  float64 `json:"avgAge"`
    MaxAge  int64   `json:"maxAge"`
}

err := driver.Exec().
    Cypher(`
        MATCH (p:Person)
        WITH count(p) AS total, avg(p.age) AS avgAge, max(p.age) AS maxAge
        RETURN {total: total, avgAge: avgAge, maxAge: maxAge} AS stats
    `).
    Run(ctx, "stats", &stats)
```

## Best Practices

1. **Use multi-line strings** for readability:
   ```go
   Cypher(`
       MATCH (u:User)
       WHERE u.active = true
       RETURN u
   `)
   ```

2. **Always use parameters** for user input (prevents injection)

3. **Use UNWIND for batch operations** instead of multiple queries

4. **Use WITH to control variable scope** in complex queries

5. **Stream large results** to avoid memory issues
