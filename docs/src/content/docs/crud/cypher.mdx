# Raw Cypher

The `Cypher()` method is the **primary way** to interact with neogo. It allows you to write raw Cypher queries while still benefiting from type-safe result binding via `Return()`.

<Aside type="tip" title="Recommended Approach">
  For most real-world queries, `Cypher()` combined with `Return(db.Qual())` is the recommended approach. It gives you the full power of Cypher while neogo handles parameter injection and result mapping.
</Aside>

## Basic Pattern

<Steps>

1. **Write your Cypher query** using `Cypher()`
2. **Bind results** using `Return(db.Qual(&variable, "expression"))`
3. **Pass parameters** using `RunWithParams(ctx, map[string]any{...})`

</Steps>

```go
var users []*User

err := driver.Exec().
    Cypher(`
        MATCH (u:User)-[:FRIENDS_WITH]->(friend:User)
        WHERE u.age > $minAge
        WITH u, count(friend) AS friendCount
    `).
    Return(db.Qual(&users, "u")).
    RunWithParams(ctx, map[string]any{
        "minAge": 18,
    })
```

## Result Binding with db.Qual

`db.Qual(&target, "expression")` binds a Cypher expression to a Go variable:

### Binding Nodes

```go
var person Person

err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id})`).
    Return(db.Qual(&person, "p")).
    RunWithParams(ctx, map[string]any{"id": "user-123"})
```

### Binding Properties

```go
var name string
var age int

err := driver.Exec().
    Cypher(`MATCH (p:Person {id: $id})`).
    Return(
        db.Qual(&name, "p.name"),
        db.Qual(&age, "p.age"),
    ).
    RunWithParams(ctx, map[string]any{"id": "user-123"})
```

### Binding Collections

```go
var users []*User

err := driver.Exec().
    Cypher(`MATCH (u:User) WHERE u.active = true`).
    Return(db.Qual(&users, "u")).
    Run(ctx)
```

### Binding Aggregations

```go
var count int64
var avgAge float64

err := driver.Exec().
    Cypher(`MATCH (u:User)`).
    Return(
        db.Qual(&count, "count(u)"),
        db.Qual(&avgAge, "avg(u.age)"),
    ).
    Run(ctx)
```

### Binding Complex Expressions

```go
var result []struct {
    UserID   string `json:"userID"`
    Name     string `json:"name"`
    FriendCount int `json:"friendCount"`
}

err := driver.Exec().
    Cypher(`
        MATCH (u:User)-[:FRIENDS_WITH]->(f)
        WITH u, count(f) AS cnt
        WITH {userID: u.id, name: u.name, friendCount: cnt} AS data
    `).
    Return(db.Qual(&result, "data")).
    Run(ctx)
```

## Parameter Injection

### Using RunWithParams

Pass parameters as a map:

```go
err := driver.Exec().
    Cypher(`
        MATCH (u:User {id: $userID})
        SET u.lastLogin = $timestamp
    `).
    RunWithParams(ctx, map[string]any{
        "userID":    "user-123",
        "timestamp": time.Now(),
    })
```

### Using UNWIND for Batch Operations

```go
var results []Answer

err := driver.Exec().
    Cypher(`
        UNWIND $inputs AS input
        MATCH (u:User {id: input.userID})-[r:ANSWERED]->(q:Question {id: input.questionID})
        WITH input, properties(r) AS answer
    `).
    Return(db.Qual(&results, "answer")).
    RunWithParams(ctx, map[string]any{
        "inputs": []map[string]any{
            {"userID": "user-1", "questionID": "q-1"},
            {"userID": "user-2", "questionID": "q-2"},
        },
    })
```

### Nested Parameters

```go
err := driver.Exec().
    Cypher(`
        MERGE (gu:User {id: $input.groupUserID})
        ON CREATE SET gu.createdAt = datetime()
        WITH gu
        UNWIND $input.userIDs AS userID
        MERGE (u:User {id: userID})
        MERGE (u)-[:IN_GROUP]->(gu)
    `).
    RunWithParams(ctx, map[string]any{
        "input": map[string]any{
            "groupUserID": "group-1",
            "userIDs":     []string{"user-1", "user-2", "user-3"},
        },
    })
```

## Combining Cypher with Builder Methods

You can chain `Cypher()` with other builder methods:

### Cypher + Return

```go
var years []*Year

err := driver.Exec().
    Cypher(`
        MATCH (c:Curriculum {id: $curriculumID})-[:HAS]->(:Strand)-[:INCLUDES]->(s:Skill)
        MATCH (n:Network)-[:INCLUDES]->(s)
        MATCH (n)-[:STUDIED_IN]->(y:Year)
    `).
    Return(db.Return(db.Qual(&years, "y"), db.Distinct, db.OrderBy("order", true))).
    RunWithParams(ctx, map[string]any{"curriculumID": curriculumID})
```

### Cypher + WITH Clause in Return

```go
var regions []*Region

err := driver.Exec().
    Cypher(`
        UNWIND $userIDs AS userID
        OPTIONAL MATCH (:User {id:userID})-[:STUDIES_IN|TEACHES_IN]->(r:Region)
        WITH {userID: userID, region: properties(r)} AS data
    `).
    Return(db.Qual(&regions, "data")).
    RunWithParams(ctx, map[string]any{
        "userIDs": userIDs,
    })
```

## Transactions with Cypher

### Within WriteTransaction

```go
session := driver.WriteSession(ctx)
defer session.Close(ctx)

err := session.WriteTransaction(ctx, func(begin func() Query) error {
    var curriculumID string
    
    if err := begin().
        Cypher(`
            MATCH (:User {id: $userID})-[r:STUDIES]->(c:Curriculum)
            WITH c.id AS curriculumID, r
            DELETE r
            WITH curriculumID
        `).
        Return(db.Qual(&curriculumID, "curriculumID")).
        RunWithParams(ctx, map[string]any{
            "userID": userID,
        }); err != nil {
        return err
    }
    
    // Use curriculumID in next query...
    return nil
})
```

## Complex Real-World Examples

### User Migration with APOC

```go
var userUUID string

err := driver.Exec().
    Cypher(`
        MATCH (u:User {id: $userID})
        OPTIONAL MATCH (nu:User {id: $newID})
        CALL apoc.do.when(
            nu IS NOT NULL,
            "
            CALL apoc.refactor.mergeNodes([nu, u], {properties: 'discard'}) YIELD node
            DETACH DELETE u
            RETURN nu.uuid AS userUUID
            ",
            "SET u.id = newID RETURN u.uuid AS userUUID",
            {u: u, nu: nu, newID: $newID}
        ) YIELD value
        WITH value.userUUID AS userUUID
    `).
    Return(db.Qual(&userUUID, "userUUID")).
    RunWithParams(ctx, map[string]any{
        "userID": oldUserID,
        "newID":  newUserID,
    })
```

### Batch Processing with CALL Subqueries

```go
var answers []map[string]any

err := driver.Exec().
    Cypher(`
        UNWIND $inputs AS input
        OPTIONAL CALL {
            WITH input
            OPTIONAL MATCH (:User {id:input.userID})-[r:ANSWERED]->(:Question {id:input.questionID})
            WHERE r.clearedAt IS NULL
            RETURN properties(r) AS answerEdge 
            ORDER BY datetime(r.createdAt) DESC 
            LIMIT 1
        }
        WITH input, answerEdge
    `).
    Return(db.Qual(&answers, "answerEdge")).
    RunWithParams(ctx, map[string]any{
        "inputs": inputs,
    })
```

### Dynamic Query Building

```go
query := `MATCH (u:User)`

if input.RegionID != nil {
    query += `
        MATCH (u)-[:STUDIES_IN]->(:Region {id: $regionID})`
}
if input.YearID != nil {
    query += `
        MATCH (u)-[:STUDIES_IN]->(:Year {id: $yearID})`
}

var users []*User
err := driver.Exec().
    Cypher(query).
    Return(db.Qual(&users, "u")).
    RunWithParams(ctx, map[string]any{
        "regionID": input.RegionID,
        "yearID":   input.YearID,
    })
```

## When to Use Cypher() vs Builder Methods

| Use `Cypher()` | Use Builder Methods |
|----------------|---------------------|
| Complex queries with subqueries | Simple CRUD operations |
| APOC procedures | Basic MATCH/CREATE/MERGE |
| Queries with CASE expressions | When type inference helps |
| Performance-critical batch operations | Learning/prototyping |
| Existing Cypher you want to reuse | When IDE autocomplete is valuable |

<Aside type="tip">
  In production codebases, `Cypher()` is typically used for 90%+ of queries because it provides full control over the Cypher syntax while neogo handles the tedious parts (parameter binding, result mapping).
</Aside>

## Best Practices

1. **Use multi-line strings** for readability:
   ```go
   Cypher(`
       MATCH (u:User)
       WHERE u.active = true
       RETURN u
   `)
   ```

2. **Always use parameters** for user input (prevents injection):
   ```go
   // ✅ Good
   Cypher(`MATCH (u:User {id: $id})`).RunWithParams(ctx, map[string]any{"id": userID})
   
   // ❌ Bad - SQL injection risk
   Cypher(fmt.Sprintf(`MATCH (u:User {id: '%s'})`, userID)).Run(ctx)
   ```

3. **Use struct tags for complex result mapping**:
   ```go
   var result []struct {
       UserID string `json:"userID"`
       Count  int    `json:"count"`
   }
   ```

4. **Leverage UNWIND for batch operations** instead of multiple queries

5. **Use WITH to control variable scope** in complex queries
