# Merge (Upsert)

The `MERGE` clause ensures a pattern exists in the graph. If the pattern doesn't exist, it creates it. If it does exist, it matches it. This is Neo4j's upsert operation.

## Basic Merge

### Merge a Node

```go
var robert any
var labels []string

err := client.Exec().
    Merge(db.Node(db.Qual(&robert, "robert", db.Label("Critic")))).
    Return(&robert, db.Qual(&labels, "labels(robert)")).
    Run(ctx)
```

```cypher
MERGE (robert:Critic)
RETURN robert, labels(robert)
```

### Merge with Properties

```go
var michael Person

err := client.Exec().
    Merge(db.Node(db.Qual(&michael, "michael", db.Props{
        "name": "'Michael Douglas'",
    }))).
    Return(&michael.Name, &michael.BornIn).
    Run(ctx)
```

```cypher
MERGE (michael:Person {name: 'Michael Douglas'})
RETURN michael.name, michael.bornIn
```

<Aside type="tip">
  Properties in MERGE patterns are used for matching. If a node with those exact properties doesn't exist, a new node is created with only those properties.
</Aside>

### Merge Derived from Existing Data

```go
var person Person
var location Location

err := client.Exec().
    Match(db.Node(db.Qual(&person, "person"))).
    Merge(db.Node(db.Qual(&location, "location", db.Props{
        "name": "person.bornIn",
    }))).
    Return(&person.Name, &person.BornIn, &location).
    Run(ctx)
```

```cypher
MATCH (person:Person)
MERGE (location:Location {name: person.bornIn})
RETURN person.name, person.bornIn, location
```

## ON CREATE and ON MATCH

Execute different actions depending on whether MERGE created or matched the pattern.

### ON CREATE

Set properties only when the node is created:

```go
var keanu Person

err := client.Exec().
    Merge(
        db.Node(db.Qual(&keanu, "keanu", db.Props{
            "name": "'Keanu Reeves'",
        })),
        db.OnCreate(db.SetPropValue(&keanu.Created, "timestamp()")),
    ).
    Return(&keanu.Name, &keanu.Created).
    Run(ctx)
```

```cypher
MERGE (keanu:Person {name: 'Keanu Reeves'})
ON CREATE
  SET keanu.created = timestamp()
RETURN keanu.name, keanu.created
```

### ON MATCH

Set properties only when the node already exists:

```go
var person Person

err := client.Exec().
    Merge(
        db.Node(db.Qual(&person, "person")),
        db.OnMatch(db.SetPropValue(&person.Found, true)),
    ).
    Return(&person.Name, &person.Found).
    Run(ctx)
```

```cypher
MERGE (person:Person)
ON MATCH
  SET person.found = true
RETURN person.name, person.found
```

### Both ON CREATE and ON MATCH

```go
var keanu Person

err := client.Exec().
    Merge(
        db.Node(db.Qual(&keanu, "keanu", db.Props{
            "name": "'Keanu Reeves'",
        })),
        db.OnCreate(db.SetPropValue(&keanu.Created, "timestamp()")),
        db.OnMatch(db.SetPropValue(&keanu.LastSeen, "timestamp()")),
    ).
    Return(&keanu.Name, &keanu.Created, &keanu.LastSeen).
    Run(ctx)
```

```cypher
MERGE (keanu:Person {name: 'Keanu Reeves'})
ON CREATE
  SET keanu.created = timestamp()
ON MATCH
  SET keanu.lastSeen = timestamp()
RETURN keanu.name, keanu.created, keanu.lastSeen
```

### Multiple Properties in ON MATCH

```go
var person Person

err := client.Exec().
    Merge(
        db.Node(db.Qual(&person, "person")),
        db.OnMatch(
            db.SetPropValue(&person.Found, true),
            db.SetPropValue(&person.LastSeen, "timestamp()"),
        ),
    ).
    Return(&person.Name, &person.Found, &person.LastSeen).
    Run(ctx)
```

```cypher
MERGE (person:Person)
ON MATCH
  SET
    person.found = true,
    person.lastSeen = timestamp()
RETURN person.name, person.found, person.lastSeen
```

## Merge Relationships

### Basic Relationship Merge

```go
var charlie Person
var wallStreet Movie
var typeR string

err := client.Exec().
    Match(
        db.Patterns(
            db.Node(db.Qual(&charlie, "charlie", db.Props{"name": "'Charlie Sheen'"})),
            db.Node(db.Qual(&wallStreet, "wallStreet", db.Props{"title": "'Wall Street'"})),
        ),
    ).
    Merge(db.Node(&charlie).To(db.Qual(ActedIn{}, "r"), &wallStreet)).
    Return(&charlie.Name, db.Qual(&typeR, "type(r)"), &wallStreet.Title).
    Run(ctx)
```

```cypher
MATCH
  (charlie:Person {name: 'Charlie Sheen'}),
  (wallStreet:Movie {title: 'Wall Street'})
MERGE (charlie)-[r:ACTED_IN]->(wallStreet)
RETURN charlie.name, type(r), wallStreet.title
```

### Multiple Relationships in a Pattern

```go
var oliver, reiner Person
var movie Movie

err := client.Exec().
    Match(
        db.Patterns(
            db.Node(db.Qual(&oliver, "oliver", db.Props{"name": "'Oliver Stone'"})),
            db.Node(db.Qual(&reiner, "reiner", db.Props{"name": "'Rob Reiner'"})),
        ),
    ).
    Merge(
        db.Node(&oliver).
            To(Directed{}, &movie).
            From(Directed{}, &reiner),
    ).
    Return(&movie).
    Run(ctx)
```

```cypher
MATCH
  (oliver:Person {name: 'Oliver Stone'}),
  (reiner:Person {name: 'Rob Reiner'})
MERGE (oliver)-[:DIRECTED]->(movie:Movie)<-[:DIRECTED]-(reiner)
RETURN movie
```

### Undirected Relationship Merge

```go
var charlie, oliver Person
var knows Knows

err := client.Exec().
    Match(
        db.Patterns(
            db.Node(db.Qual(&charlie, "charlie", db.Props{"name": "'Charlie Sheen'"})),
            db.Node(db.Qual(&oliver, "oliver", db.Props{"name": "'Oliver Stone'"})),
        ),
    ).
    Merge(
        db.Node(&charlie).Related(db.Qual(&knows, "r"), &oliver),
    ).
    Return(&knows).
    Run(ctx)
```

```cypher
MATCH
  (charlie:Person {name: 'Charlie Sheen'}),
  (oliver:Person {name: 'Oliver Stone'})
MERGE (charlie)-[r:KNOWS]-(oliver)
RETURN r
```

### Chaining Multiple MERGEs

```go
var person Person
var location Location

err := client.Exec().
    Match(db.Node(db.Qual(&person, "person"))).
    Merge(db.Node(db.Qual(&location, "location", db.Props{
        "name": "person.bornIn",
    }))).
    Merge(db.Node(&person).To(db.Qual(BornIn{}, "r"), &location)).
    Return(&person.Name, &person.BornIn, &location).
    Run(ctx)
```

```cypher
MATCH (person:Person)
MERGE (location:Location {name: person.bornIn})
MERGE (person)-[r:BORN_IN]->(location)
RETURN person.name, person.bornIn, location
```

## MERGE with Derived Properties

Create relationships with properties derived from existing nodes:

```go
type Chauffeur struct {
    neogo.Node `neo4j:"Chauffeur"`
}

type HasChauffeur struct {
    neogo.Relationship `neo4j:"HAS_CHAUFFEUR"`
}

var person Person
var hasChauffeur HasChauffeur
var chauffeur Chauffeur

err := client.Exec().
    Match(db.Node(db.Qual(&person, "person"))).
    Merge(
        db.Node(&person).To(
            db.Qual(&hasChauffeur, "r"),
            db.Qual(&chauffeur, "chauffeur", db.Props{
                "name": &person.ChauffeurName,
            }),
        ),
    ).
    Return(&person.Name, &person.ChauffeurName, &chauffeur).
    Run(ctx)
```

```cypher
MATCH (person:Person)
MERGE (person)-[r:HAS_CHAUFFEUR]->(chauffeur:Chauffeur {name: person.chauffeurName})
RETURN person.name, person.chauffeurName, chauffeur
```

## Best Practices

<Aside type="tip" title="Use Constraints">
  Create unique constraints on the properties you use in MERGE patterns. This ensures MERGE is atomic and prevents race conditions.
</Aside>

1. **Match first when possible**: If you need to MERGE a relationship between existing nodes, MATCH the nodes first
2. **Use specific properties**: Only include properties that uniquely identify the node
3. **Combine with constraints**: Use unique constraints on merge properties for safety
4. **Use ON CREATE for defaults**: Set default values in ON CREATE that won't be overwritten on subsequent merges
5. **Use ON MATCH for timestamps**: Update "last seen" or "updated at" timestamps in ON MATCH
