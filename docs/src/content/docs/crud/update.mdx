neogo provides several ways to update nodes and relationships using Cypher's `SET` clause.

## Basic Updates

### Update a Single Property

```go
var person Person

cy := c.Match(
    db.Node(&person, db.Props{"name": "Alice"}),
).Set(
    db.SetPropValue(&person, "age", 31),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person {name: "Alice"})
SET person.age = 31
RETURN person
```

### Update Multiple Properties

```go
cy := c.Match(
    db.Node(&person, db.Props{"name": "Alice"}),
).Set(
    db.SetPropValue(&person, "age", 31),
    db.SetPropValue(&person, "email", "alice@example.com"),
    db.SetPropValue(&person, "updated_at", time.Now()),
).Return(&person)
```

## SET Operations

### SetPropValue

Set a single property to a value:

```go
db.SetPropValue(&person, "age", 31)
// SET person.age = 31
```

### SetProp

Set a property from another property or expression:

```go
db.SetProp(&person, "name", db.Qual(&other, "name"))
// SET person.name = other.name
```

### SetMerge

Merge properties (add/update without removing existing):

```go
db.SetMerge(&person, db.Props{
    "age":    31,
    "email":  "alice@example.com",
    "active": true,
})
// SET person += {age: 31, email: "alice@example.com", active: true}
```

<Aside type="tip">
Use `SetMerge` when you want to update multiple properties while preserving other existing properties.
</Aside>

### SetReplace

Replace all properties (removes existing properties not in the map):

```go
db.SetReplace(&person, db.Props{
    "name": "Alice",
    "age":  31,
})
// SET person = {name: "Alice", age: 31}
```

<Aside type="caution">
`SetReplace` removes any properties not specified in the map. Use with care!
</Aside>

## Updating Labels

### Add Labels

```go
cy := c.Match(
    db.Node(&person, db.Props{"name": "Alice"}),
).SetLabels(&person, "Premium", "Verified")
```

Generated Cypher:
```cypher
MATCH (person:Person {name: "Alice"})
SET person:Premium:Verified
```

### Remove Labels

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Cond(&person, "subscription_expired", db.Equal, true),
).RemoveLabels(&person, "Premium")
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE person.subscription_expired = true
REMOVE person:Premium
```

## Updating Relationships

### Update Relationship Properties

```go
var person, friend Person
var knows Knows

cy := c.Match(
    db.Patterns(
        db.Node(&person, db.Props{"name": "Alice"}),
        db.Related(&knows, db.To, &friend, db.Props{"name": "Bob"}),
    ),
).Set(
    db.SetPropValue(&knows, "strength", 10),
    db.SetPropValue(&knows, "updated_at", time.Now()),
).Return(&knows)
```

## Conditional Updates

### Update Based on Conditions

```go
var person Person

cy := c.Match(
    db.Node(&person),
).Where(
    db.And(
        db.Cond(&person, "age", db.GreaterThanOrEqual, 18),
        db.Cond(&person, "verified", db.Equal, false),
    ),
).Set(
    db.SetPropValue(&person, "can_vote", true),
)
```

### Update Using CASE

```go
cy := c.Match(
    db.Node(&person),
).Set(
    db.SetProp(&person, "category",
        db.Lit("CASE WHEN person.age < 18 THEN 'minor' WHEN person.age < 65 THEN 'adult' ELSE 'senior' END"),
    ),
)
```

## MERGE with Updates

### ON CREATE SET

Set properties only when creating:

```go
cy := c.Merge(
    db.Node(&person, db.Props{"email": "alice@example.com"}),
).OnCreate(
    db.SetPropValue(&person, "created_at", time.Now()),
    db.SetPropValue(&person, "login_count", 0),
)
```

Generated Cypher:
```cypher
MERGE (person:Person {email: "alice@example.com"})
ON CREATE SET person.created_at = $p0, person.login_count = 0
```

### ON MATCH SET

Set properties only when matching existing:

```go
cy := c.Merge(
    db.Node(&person, db.Props{"email": "alice@example.com"}),
).OnMatch(
    db.SetPropValue(&person, "last_login", time.Now()),
    db.SetProp(&person, "login_count", db.Lit("person.login_count + 1")),
)
```

### Combined ON CREATE and ON MATCH

```go
cy := c.Merge(
    db.Node(&person, db.Props{"email": "alice@example.com"}),
).OnCreate(
    db.SetPropValue(&person, "created_at", time.Now()),
    db.SetPropValue(&person, "login_count", 1),
).OnMatch(
    db.SetPropValue(&person, "last_login", time.Now()),
    db.SetProp(&person, "login_count", db.Lit("person.login_count + 1")),
).Return(&person)
```

## Bulk Updates

### Update Multiple Nodes

```go
var person Person

cy := c.Match(
    db.Node(&person),
).Where(
    db.Cond(&person, "status", db.Equal, "pending"),
).Set(
    db.SetPropValue(&person, "status", "active"),
    db.SetPropValue(&person, "activated_at", time.Now()),
)
```

### Update with UNWIND

```go
updates := []map[string]any{
    {"id": "1", "score": 100},
    {"id": "2", "score": 85},
    {"id": "3", "score": 92},
}

var person Person

cy := c.Unwind(updates, "update").
    Match(
        db.Node(&person, db.Props{"id": db.Qual("update", "id")}),
    ).Set(
        db.SetProp(&person, "score", db.Qual("update", "score")),
    )
```

## Removing Properties

### Remove a Property

```go
cy := c.Match(
    db.Node(&person, db.Props{"name": "Alice"}),
).Remove(
    db.Qual(&person, "temporary_field"),
)
```

Generated Cypher:
```cypher
MATCH (person:Person {name: "Alice"})
REMOVE person.temporary_field
```

### Set Property to NULL

Alternatively, set to null:

```go
cy := c.Match(
    db.Node(&person),
).Set(
    db.SetPropValue(&person, "optional_field", nil),
)
```

## Update Patterns

### Increment/Decrement

```go
cy := c.Match(
    db.Node(&person, db.Props{"name": "Alice"}),
).Set(
    db.SetProp(&person, "views", db.Lit("person.views + 1")),
)
```

### Append to List

```go
cy := c.Match(
    db.Node(&person, db.Props{"name": "Alice"}),
).Set(
    db.SetProp(&person, "tags", db.Lit("person.tags + ['new_tag']")),
)
```

### Update from Another Node

```go
var person, template Person

cy := c.Match(
    db.Node(&person, db.Props{"name": "Alice"}),
).Match(
    db.Node(&template, db.Props{"name": "Template"}),
).Set(
    db.SetProp(&person, "settings", db.Qual(&template, "default_settings")),
)
```

## Best Practices

<Aside type="tip" title="Update Guidelines">

1. **Always filter updates**: Use WHERE to target specific nodes
2. **Use MERGE for upserts**: When you're not sure if data exists
3. **Return updated nodes**: Verify updates worked as expected
4. **Use transactions**: Wrap multiple updates in a transaction
5. **Consider SetMerge**: Safer than SetReplace for partial updates

</Aside>
