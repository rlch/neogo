The `WHERE` clause filters results in MATCH, OPTIONAL MATCH, and WITH clauses. neogo provides a comprehensive API for building conditions.

## Basic Conditions

### Using db.Cond

The `db.Cond` function creates a condition comparing a property to a value:

```go
var person Person

cy := c.Match(
    db.Node(&person),
).Where(
    db.Cond(&person, "age", db.GreaterThan, 30),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE person.age > 30
RETURN person
```

### Comparison Operators

| Operator | Symbol | Description |
|----------|--------|-------------|
| `db.Equal` | `=` | Equal to |
| `db.NotEqual` | `<>` | Not equal to |
| `db.LessThan` | `<` | Less than |
| `db.LessThanOrEqual` | `<=` | Less than or equal |
| `db.GreaterThan` | `>` | Greater than |
| `db.GreaterThanOrEqual` | `>=` | Greater than or equal |
| `db.In` | `IN` | In list |
| `db.Contains` | `CONTAINS` | String contains |
| `db.StartsWith` | `STARTS WITH` | String starts with |
| `db.EndsWith` | `ENDS WITH` | String ends with |
| `db.Matches` | `=~` | Regex match |

### String Operations

```go
// CONTAINS
db.Cond(&person, "name", db.Contains, "ali")
// person.name CONTAINS "ali"

// STARTS WITH
db.Cond(&person, "email", db.StartsWith, "admin")
// person.email STARTS WITH "admin"

// ENDS WITH
db.Cond(&person, "email", db.EndsWith, "@example.com")
// person.email ENDS WITH "@example.com"

// REGEX
db.Cond(&person, "phone", db.Matches, "^\\+1.*")
// person.phone =~ "^\\+1.*"
```

### IN Operator

```go
db.Cond(&person, "status", db.In, []string{"active", "pending"})
// person.status IN ["active", "pending"]
```

## Logical Operators

### AND

Combine conditions with AND:

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.And(
        db.Cond(&person, "age", db.GreaterThan, 25),
        db.Cond(&person, "age", db.LessThan, 65),
        db.Cond(&person, "active", db.Equal, true),
    ),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE person.age > 25 AND person.age < 65 AND person.active = true
RETURN person
```

### OR

Combine conditions with OR:

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Or(
        db.Cond(&person, "role", db.Equal, "admin"),
        db.Cond(&person, "role", db.Equal, "moderator"),
    ),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE person.role = "admin" OR person.role = "moderator"
RETURN person
```

### NOT

Negate a condition:

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Not(db.Cond(&person, "status", db.Equal, "banned")),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE NOT person.status = "banned"
RETURN person
```

### XOR

Exclusive OR:

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Xor(
        db.Cond(&person, "premium", db.Equal, true),
        db.Cond(&person, "trial", db.Equal, true),
    ),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE person.premium = true XOR person.trial = true
RETURN person
```

## Nested Conditions

Combine logical operators for complex conditions:

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.And(
        db.Cond(&person, "active", db.Equal, true),
        db.Or(
            db.And(
                db.Cond(&person, "age", db.GreaterThanOrEqual, 18),
                db.Cond(&person, "country", db.Equal, "US"),
            ),
            db.And(
                db.Cond(&person, "age", db.GreaterThanOrEqual, 16),
                db.Cond(&person, "country", db.Equal, "UK"),
            ),
        ),
    ),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE person.active = true AND (
    (person.age >= 18 AND person.country = "US") OR
    (person.age >= 16 AND person.country = "UK")
)
RETURN person
```

## Property Existence

### Check if Property Exists

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Cond(&person, "email", db.IsNotNull, nil),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE person.email IS NOT NULL
RETURN person
```

### Check if Property is NULL

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Cond(&person, "deleted_at", db.IsNull, nil),
).Return(&person)
```

## Comparing Properties

### Compare Two Properties

```go
var person Person
var friend Person

cy := c.Match(
    db.Patterns(
        db.Node(&person),
        db.Related(nil, db.To, &friend),
    ),
).Where(
    db.Cond(
        db.Qual(&person, "age"),
        "",
        db.GreaterThan,
        db.Qual(&friend, "age"),
    ),
).Return(&person)
```

### Compare to Expression

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Cond(&person, "login_count", db.GreaterThan, db.Lit("average_logins")),
)
```

## Pattern Predicates

### EXISTS

Check if a pattern exists:

```go
var person Person
var company Company

cy := c.Match(
    db.Node(&person),
).Where(
    db.Exists(
        db.Patterns(
            db.Node(&person),
            db.Related(db.Var("WORKS_AT"), db.To, &company),
        ),
    ),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE EXISTS { (person)-[:WORKS_AT]->(:Company) }
RETURN person
```

### NOT EXISTS

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Not(db.Exists(
        db.Patterns(
            db.Node(&person),
            db.Related(db.Var("BLOCKED"), db.Either, db.Node(nil)),
        ),
    )),
).Return(&person)
```

## Label Predicates

### Check Label

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.HasLabel(&person, "Premium"),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
WHERE person:Premium

```

## List Predicates

### ANY

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Lit("ANY(tag IN person.tags WHERE tag = 'vip')"),
).Return(&person)
```

### ALL

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Lit("ALL(score IN person.scores WHERE score > 50)"),
).Return(&person)
```

### NONE

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Lit("NONE(tag IN person.tags WHERE tag = 'banned')"),
).Return(&person)
```

### SINGLE

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Lit("SINGLE(role IN person.roles WHERE role = 'admin')"),

```

## WHERE in Different Clauses

### After MATCH

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Cond(&person, "active", db.Equal, true),
).Return(&person)
```

### After OPTIONAL MATCH

```go
cy := c.Match(
    db.Node(&person),
).OptionalMatch(
    db.Patterns(
        db.Node(&person),
        db.Related(&worksAt, db.To, &company),
    ),
).Where(
    db.Cond(&company, "industry", db.Equal, "tech"),
).Return(&person, &company)
```

### After WITH

```go
cy := c.Match(
    db.Node(&person),
).With(&person, db.Lit("count(*) as friendCount")).
    Where(db.Cond(db.Var("friendCount"), "", db.GreaterThan, 10)).
    Return(&person)
```

## Raw Cypher Conditions

For complex conditions not covered by the API:

```go
cy := c.Match(
    db.Node(&person),
).Where(
    db.Lit("person.created_at > datetime() - duration('P30D')"),
).Return(&person)
```

<Aside type="caution">
Use `db.Lit()` sparingly as it bypasses type safety. Prefer the structured API when possible.
</Aside>

## Best Practices

<Aside type="tip" title="WHERE Guidelines">

1. **Filter early**: Apply WHERE as early as possible to reduce data processed
2. **Use indexes**: Conditions on indexed properties are much faster
3. **Avoid functions on properties**: `WHERE lower(name) = 'alice'` can't use indexes
4. **Use parameters**: Always parameterize user input to prevent injection

</Aside>
