Patterns are the core of Cypher queries. neogo provides a fluent API for building patterns that match nodes, relationships, and paths.

## Pattern Building Blocks

### db.Node()

Create a node pattern:

```go
// Bound to struct
var person Person
db.Node(&person)
// (person:Person)

// With inline properties
db.Node(&person, db.Props{"name": "Alice"})
// (person:Person {name: "Alice"})

// Anonymous with label
db.Node(db.Var("Person"))
// (:Person)

// Completely anonymous
db.Node(nil)
// ()
```

### db.Related()

Create a relationship pattern:

```go
var knows Knows

// Outgoing
db.Related(&knows, db.To, &target)
// -[knows:KNOWS]->

// Incoming
db.Related(&knows, db.From, &source)
// <-[knows:KNOWS]-

// Either direction
db.Related(&knows, db.Either, &other)
// -[knows:KNOWS]-
```

### db.Patterns()

Chain nodes and relationships into a path:

```go
var a, b, c Person
var r1, r2 Knows

db.Patterns(
    db.Node(&a),
    db.Related(&r1, db.To, &b),
    db.Related(&r2, db.To, &c),
)
// (a:Person)-[r1:KNOWS]->(b:Person)-[r2:KNOWS]->(c:Person)
```

## Variable Management

### db.Var()

Create or reference a variable:

```go
// Reference a label
db.Var("Person")
// :Person

// Multiple labels/types
db.Var("KNOWS", "FRIENDS_WITH")
// :KNOWS|FRIENDS_WITH

// Reference an existing variable by name
db.Var("existingVar")
```

### db.Bind()

Bind a struct to a specific variable name:

```go
var person Person

db.Node(db.Bind(&person, "p"))
// (p:Person)

// Now use db.Qual with &person but it references "p"
db.Qual(&person, "name")
// p.name
```

### db.Qual()

Qualify a property access:

```go
var person Person

// Property access
db.Qual(&person, "name")
// person.name

// Nested property
db.Qual(&person, "address", "city")
// person.address.city

// Variable without property
db.Qual(&person)
// person
```

## Named Paths

### db.Path()

Assign a path to a variable:

```go
var person, friend Person

cy := c.Match(
    db.Path("p",
        db.Node(&person),
        db.Related(nil, db.To, &friend),
    ),
).Return(db.Var("p"))
```

Generated Cypher:
```cypher
MATCH p = (person:Person)-[]->(friend:Person)
RETURN p
```

### Path Functions

Use path functions with named paths:

```go
cy := c.Match(
    db.Path("p",
        db.Node(&start),
        db.Related(nil, db.To, &end),
    ),
).Return(
    db.Lit("length(p)"),
    db.Lit("nodes(p)"),
    db.Lit("relationships(p)"),
)
```

## Complex Pattern Examples

### Triangle Pattern

Find mutual friends:

```go
var a, b, c Person
var r1, r2, r3 Knows

cy := c.Match(
    db.Patterns(
        db.Node(&a, db.Props{"name": "Alice"}),
        db.Related(&r1, db.To, &b),
    ),
).Match(
    db.Patterns(
        db.Node(&b),
        db.Related(&r2, db.To, &c),
    ),
).Match(
    db.Patterns(
        db.Node(&c),
        db.Related(&r3, db.To, &a),
    ),
).Return(&b, &c)
```

### Hub Pattern

Find nodes connected to many others:

```go
var hub, connected Person

cy := c.Match(
    db.Patterns(
        db.Node(&hub),
        db.Related(nil, db.Either, &connected),
    ),
).With(&hub, db.Lit("count(connected) as connections")).
    Where(db.Cond(db.Var("connections"), "", db.GreaterThan, 10)).
    Return(&hub, db.Var("connections"))
```

### Multiple Relationship Types

```go
var person, contact Person

cy := c.Match(
    db.Patterns(
        db.Node(&person, db.Props{"name": "Alice"}),
        db.Related(db.Var("KNOWS", "WORKS_WITH", "FAMILY"), db.Either, &contact),
    ),
).Return(&contact)
```

Generated Cypher:
```cypher
MATCH (person:Person {name: "Alice"})-[:KNOWS|WORKS_WITH|FAMILY]-(contact:Person)
RETURN contact
```

## Pattern Expressions

### In WHERE Clause

```go
var person Person

cy := c.Match(
    db.Node(&person),
).Where(
    db.Exists(
        db.Patterns(
            db.Node(&person),
            db.Related(db.Var("MANAGES"), db.To, db.Node(db.Var("Team"))),
        ),
    ),
).Return(&person)
```

### Pattern Comprehensions

```go
cy := c.Match(
    db.Node(&person),
).Return(
    &person,
    db.Lit("[(person)-[:KNOWS]->(f:Person) | f.name] as friendNames"),
)
```

## Inline Properties

### On Nodes

```go
db.Node(&person, db.Props{
    "name":   "Alice",
    "age":    30,
    "active": true,
})
```

### On Relationships

```go
db.Related(&knows, db.To, &friend, db.Props{
    "since": 2020,
    "close": true,
})
```

### Dynamic Properties

Use `db.Qual` for dynamic property values:

```go
db.Node(&person, db.Props{
    "name": db.Qual("input", "name"),
})
```

## Multiple Patterns

### Same MATCH

Multiple independent patterns:

```go
cy := c.Match(
    db.Node(&person),
    db.Node(&company),  // Independent pattern
).Return(&person, &company)
```

Generated Cypher:
```cypher
MATCH (person:Person), (company:Company)
RETURN person, company
```

### Separate MATCH Clauses

Sequential matching:

```go
cy := c.Match(
    db.Node(&person, db.Props{"name": "Alice"}),
).Match(
    db.Patterns(
        db.Node(&person),
        db.Related(&worksAt, db.To, &company),
    ),
).Return(&company)
```

Generated Cypher:
```cypher
MATCH (person:Person {name: "Alice"})
MATCH (person)-[worksAt:WORKS_AT]->(company:Company)
RETURN company
```

## Pattern Best Practices

<Aside type="tip" title="Pattern Guidelines">

1. **Be specific with labels**: Always include labels for better performance
2. **Use directional relationships**: Prefer `db.To`/`db.From` over `db.Either` when direction is known
3. **Bind only what you need**: Don't bind relationships/nodes you won't use
4. **Use inline properties**: Faster than separate WHERE clauses
5. **Name paths**: When you need to return or analyze the path itself

</Aside>
