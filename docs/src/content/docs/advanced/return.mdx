The `RETURN` clause specifies what data a query returns. neogo provides methods for returning nodes, relationships, properties, expressions, and aggregations.

## Basic RETURN

### Return Nodes

```go
var person Person

cy := c.Match(
    db.Node(&person),
).Return(&person)
```

Generated Cypher:
```cypher
MATCH (person:Person)
RETURN person
```

### Return Multiple Items

```go
var person Person
var company Company
var worksAt WorksAt

cy := c.Match(
    db.Patterns(
        db.Node(&person),
        db.Related(&worksAt, db.To, &company),
    ),
).Return(&person, &worksAt, &company)
```

### Return Properties

```go
cy := c.Match(
    db.Node(&person),
).Return(
    db.Qual(&person, "name"),
    db.Qual(&person, "age"),
    db.Qual(&person, "email"),
)
```

Generated Cypher:
```cypher
MATCH (person:Person)
RETURN person.name, person.age, person.email
```

## Aliases

### Using db.Alias

```go
cy := c.Match(
    db.Node(&person),
).Return(
    db.Alias(db.Qual(&person, "name"), "personName"),
    db.Alias(db.Qual(&person, "age"), "personAge"),
)
```

Generated Cypher:
```cypher
MATCH (person:Person)
RETURN person.name AS personName, person.age AS personAge
```

### Aliasing Expressions

```go
cy := c.Match(
    db.Node(&person),
).Return(
    db.Alias(db.Lit("person.first_name + ' ' + person.last_name"), "fullName"),
    db.Alias(db.Lit("date().year - person.birth_year"), "age"),
)
```

## DISTINCT

### Return Distinct Values

```go
cy := c.Match(
    db.Patterns(
        db.Node(&person),
        db.Related(nil, db.To, &friend),
    ),
).Return(db.Distinct(&friend))
```

Generated Cypher:
```cypher
MATCH (person:Person)-[]->(friend:Person)
RETURN DISTINCT friend
```

### Distinct Properties

```go
cy := c.Match(
    db.Node(&person),
).Return(
    db.Distinct(db.Qual(&person, "country")),
)
```

## Ordering

### ORDER BY

```go
cy := c.Match(
    db.Node(&person),
).Return(&person).
    OrderBy(db.Asc(db.Qual(&person, "name")))
```

Generated Cypher:
```cypher
MATCH (person:Person)
RETURN person
ORDER BY person.name ASC
```

### Multiple Order Columns

```go
cy := c.Match(
    db.Node(&person),
).Return(&person).
    OrderBy(
        db.Desc(db.Qual(&person, "created_at")),
        db.Asc(db.Qual(&person, "name")),
    )
```

### Order by Alias

```go
cy := c.Match(
    db.Node(&person),
).Return(
    &person,
    db.Alias(db.Lit("size(person.tags)"), "tagCount"),
).OrderBy(db.Desc(db.Var("tagCount")))
```

## Pagination

### SKIP and LIMIT

```go
cy := c.Match(
    db.Node(&person),
).Return(&person).
    OrderBy(db.Asc(db.Qual(&person, "name"))).
    Skip(20).
    Limit(10)
```

Generated Cypher:
```cypher
MATCH (person:Person)
RETURN person
ORDER BY person.name ASC
SKIP 20
LIMIT 10
```

### Dynamic Pagination

```go
page := 3
pageSize := 25

cy := c.Match(
    db.Node(&person),
).Return(&person).
    OrderBy(db.Asc(db.Qual(&person, "name"))).
    Skip((page - 1) * pageSize).
    Limit(pageSize)
```

## Aggregations in RETURN

### Count

```go
cy := c.Match(
    db.Node(&person),
).Return(db.Lit("count(person) as total"))
```

### Collect

```go
cy := c.Match(
    db.Patterns(
        db.Node(&person),
        db.Related(nil, db.To, &friend),
    ),
).Return(
    &person,
    db.Alias(db.Lit("collect(friend.name)"), "friendNames"),
)
```

### Multiple Aggregations

```go
cy := c.Match(
    db.Node(&person),
).Return(
    db.Lit("count(person) as total"),
    db.Lit("avg(person.age) as avgAge"),
    db.Lit("min(person.age) as minAge"),
    db.Lit("max(person.age) as maxAge"),
)
```

## Expressions

### Computed Values

```go
cy := c.Match(
    db.Node(&product),
).Return(
    &product,
    db.Alias(db.Lit("product.price * 1.1"), "priceWithTax"),
    db.Alias(db.Lit("product.stock > 0"), "inStock"),
)
```

### CASE Expressions

```go
cy := c.Match(
    db.Node(&person),
).Return(
    &person,
    db.Alias(db.Lit(`
        CASE 
            WHEN person.age < 18 THEN 'minor'
            WHEN person.age < 65 THEN 'adult'
            ELSE 'senior'
        END
    `), "ageCategory"),
)
```

### List Operations

```go
cy := c.Match(
    db.Node(&person),
).Return(
    &person,
    db.Alias(db.Lit("size(person.tags)"), "tagCount"),
    db.Alias(db.Lit("head(person.tags)"), "firstTag"),
    db.Alias(db.Lit("person.tags[0..3]"), "topTags"),
)
```

## Map Projections

### Return as Map

```go
cy := c.Match(
    db.Node(&person),
).Return(
    db.Lit("person {.name, .age, .email}"),
)
```

Generated Cypher:
```cypher
MATCH (person:Person)
RETURN person {.name, .age, .email}
```

### Map with Computed Properties

```go
cy := c.Match(
    db.Node(&person),
).Return(
    db.Lit("person {.name, .age, fullName: person.first_name + ' ' + person.last_name}"),
)
```

## Functions in RETURN

### String Functions

```go
cy := c.Match(
    db.Node(&person),
).Return(
    db.Alias(db.Lit("toUpper(person.name)"), "upperName"),
    db.Alias(db.Lit("size(person.bio)"), "bioLength"),
    db.Alias(db.Lit("left(person.bio, 100)"), "bioPreview"),
)
```

### Date Functions

```go
cy := c.Match(
    db.Node(&person),
).Return(
    &person,
    db.Alias(db.Lit("date(person.created_at)"), "createdDate"),
    db.Alias(db.Lit("duration.between(person.created_at, datetime())"), "age"),
)
```

### Path Functions

```go
cy := c.Match(
    db.Path("p",
        db.Node(&start),
        db.Related(nil, db.To, &end),
    ),
).Return(
    db.Lit("nodes(p) as pathNodes"),
    db.Lit("relationships(p) as pathRels"),
    db.Lit("length(p) as pathLength"),
)
```

## Result Handling in Go

### Single Result

```go
result, err := cy.Single(ctx, tx)
if err != nil {
    return err
}
fmt.Println(result.Person.Name)
```

### All Results

```go
results, err := cy.All(ctx, tx)
for _, r := range results {
    fmt.Printf("%s: %d years old\n", r.Person.Name, r.Person.Age)
}
```

### Streaming

```go
err := cy.Stream(ctx, tx, func(r *Result) error {
    fmt.Println(r.Person.Name)
    return nil
})
```

## Best Practices

<Aside type="tip" title="RETURN Guidelines">

1. **Return only what you need**: Don't return entire nodes if you only need properties
2. **Use aliases for clarity**: Make result columns self-documenting
3. **Aggregate early with WITH**: Use WITH for intermediate aggregations
4. **Apply ORDER BY and LIMIT together**: Sorting without limiting can be expensive
5. **Use DISTINCT judiciously**: It adds processing overhead

</Aside>

### Efficient Returns

```go
// ❌ Returns entire node (more data)
cy := c.Match(db.Node(&person)).Return(&person)

// ✅ Returns only needed properties (less data)
cy := c.Match(db.Node(&person)).Return(
    db.Qual(&person, "name"),
    db.Qual(&person, "email"),
)
```
