Relationships connect nodes in Neo4j. In neogo, relationships are defined as Go structs that embed `neogo.Relationship`.

## Basic Relationship Definition

To define a relationship, create a struct that embeds `neogo.Relationship` with a type tag:

```go
import "github.com/rlch/neogo"

type Knows struct {
    neogo.Relationship `neo4j:"KNOWS"`

    Since int `neo4j:"since"`
}
```

The `neo4j:"KNOWS"` tag defines the Neo4j relationship type.

## Relationship Base Type

The `neogo.Relationship` type provides:

```go
type Relationship struct{}

func (Relationship) IsRelationship()
```

Relationships don't have IDs like nodes - they're identified by their start node, type, and end node.

## Properties on Relationships

Like nodes, relationships can have properties:

```go
type WorksAt struct {
    neogo.Relationship `neo4j:"WORKS_AT"`

    Since      time.Time `neo4j:"since"`
    Department string    `neo4j:"department"`
    Position   string    `neo4j:"position"`
    Salary     *float64  `neo4j:"salary"`  // Optional
}
```

## Creating Relationships

Create relationships with raw Cypher:

```go
// First create/match the nodes, then create the relationship
err := driver.Exec().
    Cypher(`
        MATCH (a:Person {id: $aID})
        MATCH (b:Person {id: $bID})
        CREATE (a)-[:KNOWS {since: $since}]->(b)
    `).
    RunWithParams(ctx, map[string]any{
        "aID":   "person-1",
        "bID":   "person-2",
        "since": 2023,
    })
```

Create with properties from a struct:

```go
knows := Knows{Since: 2023}

err := driver.Exec().
    Cypher(`
        MATCH (a:Person {id: $aID})
        MATCH (b:Person {id: $bID})
        CREATE (a)-[r:KNOWS {since: $since}]->(b)
        RETURN r
    `).
    RunWithParams(ctx, map[string]any{
        "aID":   "person-1",
        "bID":   "person-2",
        "since": knows.Since,
    }, "r", &knows)
```

## Querying Relationships

### Query nodes via relationships

```go
var friends []Person

err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})-[:KNOWS]->(friend:Person)
        RETURN friend
    `).
    RunWithParams(ctx, map[string]any{"id": "person-1"}, "friend", &friends)
```

### Query relationship properties

```go
var knows Knows

err := driver.Exec().
    Cypher(`
        MATCH (a:Person {id: $aID})-[r:KNOWS]->(b:Person {id: $bID})
        RETURN r
    `).
    RunWithParams(ctx, map[string]any{
        "aID": "person-1",
        "bID": "person-2",
    }, "r", &knows)

fmt.Printf("Friends since: %d\n", knows.Since)
```

### Query with both nodes and relationships

```go
var person, friend Person
var knows Knows

err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})-[r:KNOWS]->(f:Person)
        RETURN p, r, f
        LIMIT 1
    `).
    RunWithParams(ctx, map[string]any{"id": "person-1"},
        "p", &person,
        "r", &knows,
        "f", &friend)
```

## Relationship Directions

In Cypher, relationships have three possible directions:

| Direction | Cypher | Description |
|-----------|--------|-------------|
| Outgoing | `-[:TYPE]->` | From start to end node |
| Incoming | `<-[:TYPE]-` | From end to start node |
| Either | `-[:TYPE]-` | Any direction |

```go
// Outgoing: who does Alice know?
err := driver.Exec().
    Cypher(`MATCH (a:Person {name: 'Alice'})-[:KNOWS]->(friend) RETURN friend`).
    Run(ctx, "friend", &friends)

// Incoming: who knows Alice?
err := driver.Exec().
    Cypher(`MATCH (a:Person {name: 'Alice'})<-[:KNOWS]-(friend) RETURN friend`).
    Run(ctx, "friend", &friends)

// Either direction
err := driver.Exec().
    Cypher(`MATCH (a:Person {name: 'Alice'})-[:KNOWS]-(friend) RETURN friend`).
    Run(ctx, "friend", &friends)
```

## Multiple Relationship Types

Match multiple relationship types:

```go
err := driver.Exec().
    Cypher(`
        MATCH (p:Person)-[:KNOWS|FRIENDS_WITH]->(other:Person)
        RETURN other
    `).
    Run(ctx, "other", &others)
```

## Relationship Chains

Match multi-hop patterns:

```go
// Friends of friends
err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})-[:KNOWS]->()-[:KNOWS]->(fof:Person)
        WHERE fof.id <> $id
        RETURN DISTINCT fof
    `).
    RunWithParams(ctx, map[string]any{"id": "person-1"}, "fof", &friendsOfFriends)
```

## Variable-Length Paths

```go
// 1 to 3 hops
err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})-[:KNOWS*1..3]->(connected:Person)
        RETURN DISTINCT connected
    `).
    RunWithParams(ctx, map[string]any{"id": "person-1"}, "connected", &connected)
```

## Updating Relationships

```go
err := driver.Exec().
    Cypher(`
        MATCH (a:Person {id: $aID})-[r:KNOWS]->(b:Person {id: $bID})
        SET r.since = $since, r.strength = $strength
    `).
    RunWithParams(ctx, map[string]any{
        "aID":      "person-1",
        "bID":      "person-2",
        "since":    2020,
        "strength": 10,
    })
```

## Deleting Relationships

```go
// Delete specific relationship
err := driver.Exec().
    Cypher(`
        MATCH (a:Person {id: $aID})-[r:KNOWS]->(b:Person {id: $bID})
        DELETE r
    `).
    RunWithParams(ctx, map[string]any{
        "aID": "person-1",
        "bID": "person-2",
    })

// Delete all relationships of a type from a node
err := driver.Exec().
    Cypher(`
        MATCH (p:Person {id: $id})-[r:KNOWS]-()
        DELETE r
    `).
    RunWithParams(ctx, map[string]any{"id": "person-1"})
```

## Schema Tags for Relationships

Add indexes and constraints to relationship properties:

```go
type WorksAt struct {
    neogo.Relationship `neo4j:"WORKS_AT"`

    EmployeeID string `neo4j:"employee_id,unique"`  // Unique on relationship
    StartDate  string `neo4j:"start_date,index"`   // Index for fast lookups
}
```

## Best Practices

1. **Use meaningful relationship types**: `KNOWS`, `WORKS_AT`, `CREATED` are better than generic names
2. **Add properties for metadata**: Timestamps, weights, etc.
3. **Use MERGE for idempotent creates**: Prevents duplicate relationships
4. **Consider direction**: Choose the direction that makes semantic sense
5. **Index frequently filtered properties**: Especially for WHERE clauses on relationship properties
