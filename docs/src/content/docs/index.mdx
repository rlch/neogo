## Why neogo?

<CardGrid stagger>
	<Card title="Type-Safe Queries" icon="approve-check">
		Write Cypher queries with full Go type safety. Struct fields become properties, embedded types define labels.
	</Card>
	<Card title="Zero Boilerplate" icon="rocket">
		Automatic marshalling between Go structs and Neo4j nodes/relationships. No manual parameter binding.
	</Card>
	<Card title="Fluent API" icon="pencil">
		Chainable methods that mirror Cypher clauses. Generate readable, debuggable queries.
	</Card>
	<Card title="Full Cypher Support" icon="puzzle">
		MATCH, CREATE, MERGE, SET, DELETE, WITH, UNWIND, UNION, and more. Variable-length paths and pattern predicates included.
	</Card>
</CardGrid>

## Quick Example

```go
type Person struct {
	neogo.Node `neo4j:"Person"`

	Name string `neo4j:"name"`
	Age  int    `neo4j:"age"`
}

func main() {
	driver, _ := neogo.New(
		"neo4j://localhost:7687",
		neo4j.BasicAuth("neo4j", "password", ""),
		neogo.WithTypes(&Person{}),
	)

	// Query with raw Cypher + type-safe result binding
	var people []*Person
	
	err := driver.Exec().
		Cypher(`
			MATCH (p:Person)-[:KNOWS]->(friend:Person)
			WHERE p.age > $minAge
			WITH p, count(friend) AS friendCount
			WHERE friendCount > 5
		`).
		Return(db.Qual(&people, "p")).
		RunWithParams(ctx, map[string]any{
			"minAge": 21,
		})
}
```

**The pattern:** Write expressive Cypher, bind results to Go types with `db.Qual()`, pass parameters safely with `RunWithParams()`.
