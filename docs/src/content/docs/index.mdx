## Quick Example

```go
import "github.com/rlch/neogo"

type Person struct {
    neogo.Node `neo4j:"Person"`

    Name string `neo4j:"name"`
    Age  int    `neo4j:"age"`
}

func main() {
    driver, _ := neogo.New(
        "neo4j://localhost:7687",
        neo4j.BasicAuth("neo4j", "password", ""),
        neogo.WithTypes(&Person{}),
    )
    defer driver.DB().Close(ctx)

    // Write raw Cypher, bind results to Go types
    var people []Person
    err := driver.Exec().
        Cypher(`
            MATCH (p:Person)
            WHERE p.age > $minAge
            RETURN p
        `).
        RunWithParams(ctx, map[string]any{"minAge": 21}, "p", &people)
}
```

**The pattern:** Write Cypher, pass parameters, bind results with name/pointer pairs.
